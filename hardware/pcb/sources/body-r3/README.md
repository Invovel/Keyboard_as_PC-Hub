# R3 模块接口载板草稿

> 本工程保留为历史被动接口载板。本轮没有修改KiCad文件；R3.1原生Core与Dock电气仍待设计，见[最新审查](../../../../docs/R3_1_ENGINEERING_REVIEW.md)。下文100W单体供电及旧生成器说明不代表当前Core结构；不要运行旧生成器覆盖新版参数/图纸，KiCad后续修改须通过Konnect。

这是基于当前已运行固件 GPIO 与模块拓扑生成的 **KiCad 接口原理图 + PCB 布局草稿**。不是 Keychron PCB 的复刻，也不是制造放行板。

按[桌面供电底座定位](../../../../docs/desktop-power-dock.md)，本板是控制载板。新增100W等级PD输入、5V分路供电与USB7206C Hub需要单独子板，**本板J9仍只接5V**；更新产品定位没有实现这些电源电路。

- [body-r3.kicad_pro](body-r3.kicad_pro)：项目入口。
- [body-r3.kicad_sch](body-r3.kicad_sch)：内嵌连接器符号的原理图，11 个逻辑接口。
- [body-r3.kicad_pcb](body-r3.kicad_pcb)：216×64×1.6 mm 板框、34 个网络（包含空网络编号 0）、15 个封装（含安装孔）。**没有走线与铺铜**。
- [generate.py](generate.py)：已停用的旧入口，返回非零且不写文件；[原生成源文本](generate-r3-legacy.py.txt)只供历史阅读。新机械/参数用[update_r3_1.py](../../../enclosure/tools/update_r3_1.py)，后续KiCad变更经Konnect。
- [导出目录](../../exports/body-r3-review/README.md)：接口表、草稿 BOM、布局 SVG、未决事项。

## 可以从现有连接推导什么

屏幕 QSPI、触控 I²C、四键、按压、编码器 A/B、功放 I²S 与新增麦克风 I²S1 的逻辑网络已经明确，因而可以画出模块接口和连接关系。现有 ESP32-S3 开发板的精确型号、针脚排布、安装孔及屏幕背板/FPC 封装未测量，因此 J1/J2 使用**新定义的线束接口**，不假设某块开发板能直接插到这里。

J3/J4 等引脚号也是本载板新定义的线束顺序，不是宣称现有屏幕插座顺序。实际接线必须按模块丝印制作转接线，屏幕排线没有被替换成猜测的 FPC 封装。

## GPIO 基准与歧义处理

当前运行源码和双向日志支持编码器 A=1、B=2、①键=42。用户曾描述把 B 接到 42 后恢复，但当时没有改固件；因此这条口头描述不能直接冻结为 PCB 的 B=42，否则与①键冲突。本草稿以运行源码为基准保留独立网络，实物最终复核前不下单。

## 供电、USB 与磁吸边界

- 本板假设 5V_BODY 和 3V3 来自外部现有模块；没有集成稳压器、反灌保护或 PD。
- J9 是逻辑电源入口，不是 USB-C/PD 端口。现有 USB HID 继续走开发板原生 USB 口；本草稿没有路由 GPIO19/20、高速 USB 或 Hub。
- J10/J11 是左右磁吸转接的焊盘候选。磁吸附件为 DNP，5V_MAG_PROTECTED、3V3_MAG_ISOLATED、MAG_SDA/SCL 等网络未与主体电源/触控总线直连。需要后续限流、热插拔隔离、检测及连接器选型。
- 接点在主板顶面，距外壳端面约 8 mm；需独立 90° 转接小板/柔性连接到端面，不能把平面焊盘当作已完成侧向 pogo 结构。
- 100 nF 及 100 kΩ 等麦克风外围由现成模块承担或后续小板补齐；本次模块载板没有实现裸 INMP441 芯片电路。

## 检查结果

已由 `kiutils 1.4.8` 解析读取 PCB 和原理图，确认网络与接口文件可读；没有安装 KiCad，因此**没有运行 KiCad ERC、DRC，也未确认在 GUI 中打开的效果**。没有 Gerber、贴片坐标或生产就绪声明。

下一步是冻结真实模块封装及主控方案，确定电源/Hub/触点保护，然后布线与 DRC；不能从连接日志自动推断器件机械尺寸或高速电气设计。
