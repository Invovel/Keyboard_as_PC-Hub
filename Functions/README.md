# 60% 键盘一体化编程拓展模块 - 模块A（STM32 版）
## 1. 项目概述
本项目为 **60% 机械键盘专用右侧一体化拓展模块（模块A）**，采用 **STM32F103C8T6** 主控，外壳长度与 60% 键盘完全一致，小键盘式分区布局；
通过 **USB-C 直插键盘左上角母座** 连接，**仅从外部充电器供电、不从电脑取电**；
集成高速 USB Hub、编程快捷键、类雷蛇左右拨片、音量/亮度旋钮、状态指示灯，支持后续模块化拓展（模块B/C/D…），专为 VS Code 等编程场景优化。

---

## 2. 核心设计特性
- **形态适配**：外壳与 60% 键盘等长，小键盘分区布局，三面包围防尘结构
- **连接方式**：USB-C 直插键盘左上母座，卡扣固定，无多余线材
- **供电方案**：完全外部供电，支持 PD 快充，电脑 USB 仅做数据传输
- **接口配置**：USB3.0 高速 Hub，多口同时支持键鼠、耳机接收器、高速数据传输
- **控制逻辑**
  - 单旋钮：默认音量 → 按压切换屏幕亮度，LED 状态指示
  - 复位拨片：类雷蛇滚轮逻辑，按住连续触发、松手停止、自动复位
    - 短按：VS Code 标签页切换
    - 长按：全局窗口切换
  - 热插拔机械按键：VS Code 高频编程快捷键
- **数据架构**：统一 `Hub_for_PC` 数据出口，所有外设/拓展模块数据流统一管理
- **拓展性**：标准化接口，后续模块只需实现占位函数即可无缝接入

## 3. 硬件规格
### 3.1 主控
- STM32F103C8T6（最小系统板）

### 3.2 接口清单
| 接口名称          | 数量 | 功能说明                                   |
|-------------------|------|--------------------------------------------|
| Hub_for_PC        | 1    | 与电脑连接，**仅数据传输、不取电**         |
| USB-C 口          | 2    | 支持耳机接收器、高速数据传输               |
| USB-A 口          | 3    | 支持鼠标、键盘接收器、U盘高速数据传输      |
| 外部供电口        | 1    | Type-C 输入，接 100W/120W 充电器           |
| 键盘连接口        | 1    | 凸出 USB-C 公头，直插键盘左上母座          |

### 3.3 控制组件
- EC11 旋转编码器（带按压 + 双色 LED）×1
- 复位型 3 档拨片开关（类雷蛇滚轮）×1
- Kailh 热插拔底座 + MX 轴 ×5
- 0.96寸 OLED（可选）
- 状态指示灯 ×4

## 4. 供电方案（推荐选型）
### 最优选择
**CUKTECH 酷态科 10 号 120W 四口氮化镓充电器**
- 4 口输出，桌面统一供电
- PD/PPS 全协议，5V 输出稳定
- 支持米家 APP，功率监控、过载保护
- 功率余量充足，支持所有后续拓展模块

### 次选
**一加 100W 手机充电器**
- 功率足够，5V 输出稳定
- 仅单口，需额外拓展插排

### 不推荐
**三星 45W 充电器**
- 功率余量不足，拓展后易供电不足
- 协议兼容性差

### 代码预留两种供电模式
```c
uint8_t CHARGE_ChargerSupply_Init(void);      // 独立充电器供电（一加/三星）
uint8_t CHARGE_ChargeStationSupply_Init(void); // 桌面充电站供电（酷态科）
```

## 6. 核心模块说明
### 6.1 main.c
- 系统初始化 + 非阻塞时间片轮询调度
- 统一调度：按键、旋钮、拨片、指示灯、供电、USB 数据、拓展模块
- 无阻塞 `delay`，所有任务按固定周期执行

### 6.2 charge.c / charge.h
- 外部供电管理（5V 稳压、过压/过流保护）
- USB-C / USB-A 端口状态检测、数据转发
- 两种供电模式占位函数
- 与 `Hub_for_PC` 联动转发外设数据

### 6.3 hub_for_pc.c / hub_for_pc.h
- **唯一与电脑通信的数据出口**
- 支持：HID 按键、多媒体、Hub 外设转发、拓展模块数据
- 预留回调接口，新增模块无需修改核心代码

### 6.4 trigger.c / trigger.h
- 复位拨片驱动（类雷蛇巴塞利斯蛇滚轮）
- 逻辑：按住连续触发 → 松手停止 → 自动复位
- 短按：标签页切换；长按：窗口切换

### 6.5 light.c / light.h
- 系统状态指示灯
  - 旋钮模式（音量/亮度）
  - 供电模式
  - 调试状态
  - USB 高速传输状态
- 支持常亮、慢闪、快闪

## 7. 拓展模块规划（按字母命名）
- 模块A：本项目（主控 + Hub + 基础控制）
- 模块B：额外热插拔按键拓展
- 模块C：RGB 灯效同步
- 模块D：无线接收器集成
- 模块E：迷你摇杆 / 滚轮拓展

所有拓展模块统一接口：
```c
void Init(void);
void Loop(void);
void DeInit(void);
```

## 8. 使用说明
1. 硬件焊接
   - STM32 最小系统 + USB3.0 Hub（VL813）
   - 拨片、旋钮、热插拔轴、指示灯按 `config.h` 引脚接线
2. 软件编译
   - 基于 STM32CubeMX + Keil MDK
   - 开启 USB 复合设备（HID + CDC）
3. 供电连接
   - 电脑仅插 `Hub_for_PC` 口（数据）
   - 供电口接 120W/100W 充电器
4. 组装固定
   - 外壳与键盘等长，卡扣固定在键盘左侧
   - USB-C 公头插入键盘左上供电口

---

## 9. 注意事项
- **严禁从电脑 USB 取电**，必须使用外部充电器供电
- USB3.0 高速线需做屏蔽处理，避免干扰
- 拨片/旋钮为非阻塞驱动，不可添加阻塞延时
- 热插拔轴请在断电状态下更换
- 拓展模块必须使用预留接口，不修改核心框架
