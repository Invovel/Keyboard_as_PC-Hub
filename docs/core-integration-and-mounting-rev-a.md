# Core Rev A：主板集成、外接件和安装位的确定分工

2026-10-22。面向当前228×76 Core，不改变已运行固件的GPIO。结构与接口职责按下表执行；完整制造BOM与板图放行须另经原理图、封装、供电和装配验证。新电气原理图采用独立的Core-Control-RevA，保留旧载板原图。

## 直接集成到主板

| 功能 | 本版处理 | PCB及结构要求 |
| --- | --- | --- |
| 主控 | ESP32-S3-WROOM-1U-N16R8模组贴装，取代开发板和GPIO扩展板 | 模组下焊盘、去耦、EN/BOOT及下载；外置天线留独立座和塑料区，不能被金属马达/MAG遮住 |
| 3.3V | 集成稳压、输入去耦和测试点 | 稳压能力与USB实际供电预算分别计算，不能把芯片额定电流当作电脑允许电流 |
| 触觉驱动 | 两路DRV2605L、各自去耦/REG电容，默认LRA | 优先直接贴装；两路差分输出各到两针马达座；参数未实测前不写死马达额定电压 |
| 双驱动通信 | 两通道I²C复用/隔离，避免两个0x5A地址冲突 | 主总线沿用GPIO8/9，触控继续直连主总线，马达驱动分别进隔离通道 |
| 输入电路 | 四键、编码器、禁用及未来中央按压的上拉/滤波和接口 | 不把机械输入器件强行移到感应圆心；按现有映射接网，硬件滤波不破坏编码器双路相位 |
| USB FS控制端 | ESP32原生USB19/20、必要保护和测试点 | 是Hub的P6下游终端；不是电脑第二上行，不把USB3差分信号接入ESP32 |
| 屏/触控/音频/麦克风 | 在主板集成连接器和必要供电/电平处理 | 屏幕控制IC已在现有屏板上，不重复在主板放ST77916；现有模块接口经实物/线束对照 |
| 调试 | EN、BOOT、UART和电源测试点 | 调试座不高于机构净空，FTDI不要求永久焊在主板；保留外部下载能力 |

Hub、USB-C CC/翻转/ESD、各口限流和PC/Dock反灌保护**从产品目标上也应集成主板**，但尚未具备制造定版条件，见下方未冻结项；不能用控制子电路完成来宣称整机Hub完成。MAX98357A旧音频实现保留为外接/DNP选项，新机不要求扬声器声腔。

## 保留安装位、基座和插线

| 部件 | 留什么 | 具体位置/连接 |
| --- | --- | --- |
| 圆屏/触控模块 | 防转活动托架、排线折弯和可拆座 | 圆心O不动；屏体Ø44.32、AAØ38.16、屏厚预算3.5；QSPI六信号和触控四线分别连接 |
| 外旋转环 | 轴承/导向/限位，侧置传动安装空间 | Ø60，只转动；中央屏可触控及独立按压。EC11不放到屏幕后圆心挡住托架 |
| 四主体键 | 上壳导向、回弹、四个输入座 | 感应中心(±65,±18)固定；现阶段普通开关，后续eFlesh/传感板作为可替换上层件，不提前焊死未定传感器 |
| EC11 | 侧置固定/传动基座及四线座 | A→GPIO1、B→GPIO2、SW→GPIO39、公共端GND；不更改已通过测试的软件映射 |
| 中央独立按压 | 三点承力、防转和行程限位；独立两针预留 | JS1保留，GPIO尚未确定；不与EC11的GPIO39混算成两个独立输入 |
| 7 Plus马达×2位置 | 两端顶面下可拆夹持托片，马达本体不焊死主板 | 每侧15×54×6，中心(±93,−3)，长边沿Y；可只装一侧，另一侧DNP；两针柔性线到驱动OUT+/OUT− |
| 马达固定 | 在顶壳内筋提供托片承力面，夹持安装耳；可换托片 | 不在PCB钻“苹果原装孔”；不猜三颗安装耳孔距。可先用托片卡持及薄绝缘定位，固定结构计入装配包络，顶面保持完整 |
| 磁吸端面 | 左右独立竖板/端面座、触点、磁铁和承力结构 | 外侧X=±114，8触点及Y=±27磁铁保持原位；JG1/JG2只是主板内部低速线束接口 |
| 可调键盘Type-C公头 | 可调支架、插入力承力、专用USB2线束 | 公头独立于大板，不能靠USB焊盘承受键盘方向扭矩；不要求与键盘边框齐平 |
| INMP441选件 | 模块安装位和声路，主板六针预留 | GPIO4/5/17、3.3V、GND及声道选择依模块核对；默认不装，不在完整留白的顶面开声孔 |
| 天线 | 模组同轴连接/独立固定区 | 以实际天线与线长设计，不放马达正下方或MAG磁铁旁就宣称射频通过 |
| 底部Dock | DATA/PWR/CTRL配对座及承力定位 | 继续分离于Core；外形研究区不等于已选连接器或已确定针序 |

主板暂保留四个机壳安装孔(±104,±28)、Ø2.4。屏、键、马达等优先固定于机壳各自支架，不盲目给大板增加孔。需要的屏背孔、原装EC11插脚及苹果安装耳孔距均依实际件/最终机构决定，未核实的坐标不标为加工值。

## 当前连接职责

| 接口 | 职责和信号 |
| --- | --- |
| JL1 | LCD：CS16、SCK6、D0=15、D1=7、D2=11、D3=12 |
| JT1 | 触控/现有屏板供电：SDA8、SCL9、3.3V、GND；不是5V屏接口 |
| JK1/2/3/4 | 按键信号依次GPIO42/41/40/38，各自另一端接GND |
| JE1 | 编码器A1、B2、SW39、GND |
| JP1 | BOOT/禁用GPIO0与GND；上电按住涉及启动模式，需在使用说明保留 |
| JS1 | 未来中央屏独立按压，GPIO待分配 |
| JA1 | 可选既有MAX98357A：BCLK47、LRC48、DIN21、5V、GND；其余脚按模块确认 |
| JM1 | 可选INMP441：BCLK4、WS5、SD17、3.3V、GND、L/R按模块处理 |
| JH1/JH2 | 六针驱动转接/调试预留；直接集成DRV时默认DNP；不能接马达线圈 |
| 新增两针输出座 | 各路DRV的OUT+/OUT−，专供7 Plus最外侧两测试焊盘；均不接GND |
| JU1 | MCU USB FS终端链路；真实USB差分保护/路由服从原理图，不以GH线束实现高速Hub |

上表确定信号职责，不假定任意市售连接器的脚位顺序相同。对应实际针序和器件编号须由原理图输出的连接表核对后，才标为可制作线束。

## 完整连线执行顺序与明确未决项

1. 保留旧工程和库的字节备份，先完成已明确的Core控制电路及外接接口原理图。逐件核对厂商引脚、库符号和封装焊盘，不从GPIO名字猜模组脚号。
2. 完成电源、EN/BOOT、MCU、输入/显示接口、双触觉驱动和总线隔离的接网；独立做短路检查、ERC和可读渲染。
3. 在新原理图检查后才预检同步PCB，保留安装孔、圆心、感应中心、马达装配区及侧面触点。同步必须给出实际新增、保留和删除清单。
4. 按真实料号布局和布线，低速、供电、USB FS分别校核；独立检查马达输出环路与传感/麦克风串扰。未连接的高速部分不画装饰性铜线。
5. Hub整机剩余工作：USB7206C最终供电/时钟/配置与功耗；CC控制器/SS翻转器/ESD/限流及PC-Dock电源选择；USB-C/A真实插座；Dock DATA/PWR/CTRL配对件、镜像针序和高度。它们仍未冻结，本轮不能诚实地交付“整机全部连线且可打样”。
6. 高速部分确定后，核定叠层/差分阻抗/制造规则，完成全板布线及地回流、DRC、ERC、网表一致性和3D装配检查，最后才输出制造文件。
