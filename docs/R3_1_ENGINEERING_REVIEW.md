# R3.1：WP1电气与WP2结构审查

2026-10-19，资料级评审。输入为[交接基准](R3_1_CODEX_HANDOFF.md)和现有源码/接口CSV；没有将未布线R3载板当作原生Rev A PCB。结论：**架构可以继续收敛，当前不能放行原理图/PCB或保证任意电脑单线满功能。**

## 1. Hub端口、供电与独立启动

USB7206C保留为候选。官方DS00003850F说明有五个Gen2下游和一个USB2下游，需3.3V与1.15V核心电源；支持上电配置绑带、内部ROM及外部SPI配置。因此存在脱离ESP32启动的设计路线，具体配置仍须验证。官方资料没有替本产品证明总线供电合规性。[数据手册§2、§5、§9](https://www.microchip.com/content/dam/mchp/documents/NCS/ProductDocuments/DataSheets/USB7206C-Data-Sheet-DS00003850.pdf)。

| 本项目逻辑口 | 分配 | 芯片能力核对 |
| --- | --- | --- |
| P1/P2 | A1/A2 | 各需USB3+USB2兼容链路 |
| P3 | FAST-C | 需USB3+USB2、CC Source、翻转与开关 |
| P4 | Dock DATA | 需USB3+USB2；Rev A缺席时保持空置、检测与保护 |
| P5 | KBD | 只用USB2；高速部分不用不等于可以不按厂商要求终端处理 |
| P6 | ESP32 CTRL | USB2 Full-Speed HID，设为内部非可移除设备候选 |

这与5+1能力数量相容，但不是芯片管脚/封装网络冻结。Hub自身的桥接/HFC功能不替代ESP32，也不启用FlexConnect来形成第二上行。

独立启动要求：用电源监控/RC及厂商时序保持RESET_N，电源稳定后释放；自启动配置不等待ESP32写寄存器。ESP32管理连接不得长时间拉低Hub复位或卡住启动总线。复测时保持ESP32在复位、崩溃或未烧程序，检查键盘和普通外设是否仍枚举。这里的独立性只针对ESP32故障，不承诺Hub故障或系统掉电时仍有通信。

特别检查启动I²C/SMBus上拉与配置绑带：Microchip硬件检查表提示对应启动配置可等待外部控制器。不能把Hub管理线直接接到ESP32带上拉的触控总线后就声称独立启动；电气分段/启动配置必须验证。[官方硬件检查表](https://www.microchip.com/content/dam/mchp/documents/UNG/ProductDocuments/DesignChecklist/USB7206C-Hardware-Design-Checklist-DS00003336.pdf)。

## 2. 单线功率不能照搬旧46W

Core PC-C固定为电脑UFP和受电端，不在Core协商20V。必须检测实际CC电流能力并满足USB配置/挂起规则，不能只装Rd后按3A取电。TI说明Type-C端口存在Default、1.5A和3A能力，Source需CC与电源开关配合；这些是端口能力条件，不是所有电脑承诺。[TI USB-C供电说明](https://www.ti.com/lit/SLYY228)。

| 输入情形 | 规划处理，不是实测能力 |
| --- | --- |
| 初始连接、尚未配置 | 按适用USB/Type-C条件限制浪涌和启动负载；先测Hub/MCU/屏幕能否受限启动 |
| Default USB电力 | 根据实际链路与配置预算；不能把USB3配置后的额度当作上电瞬间授权，也不能按每个下游各分同样总电流 |
| CC实际宣告5V/1.5A或3A | 毛输入分别7.5W/15W；还要扣除电缆压降、Hub/各电源轨、主控和音频峰值，才是下游余量 |
| Dock增强模式 | 以Dock保护、连接器额定、转换/闭壳温升及Core路径上限重新计算；尚无确定总瓦数 |

预算采用：`下游可用功率 = 输入允许功率 − Core实测峰值 − 转换损失 − 余量`。目前Core峰值、实际Hub负载和余量未测，不填写假的每口可持续电流。Core功能、键盘优先；外部SSD、满背光、音频峰值、附件同时工作不是默认保证。若预算不足，需定义清晰受限功能/主机条件，再验证枚举与取电规则，不用简单相减取代USB合规设计。

## 3. 电源路径与接口保护

PC VBUS与Dock 5V是两个输入，经各自保护、反向截止与电源选择形成Core系统5V，禁止硬并联。Hub上行VBUS检测继续参考PC口本身，不能被Dock伪造为电脑在线。控制载板J9仍只允许5V。

TPS2121可作为电源选择研究候选，厂商给出反向截止/限流等能力，但其电流等级不能沿用旧9.2A目标；料号、限流、压降、启动和切换配置需计算后定。[TI产品资料](https://www.ti.com/product/TPS2121)。不保证插拔Dock时SSD写入不中断，允许依据完整电源/USB配置进行受控重新枚举。

| 部位 | 必需设计 |
| --- | --- |
| PC-C | CC Sink/方向识别、SS Mux、ESD、VBUS检测、受限启动/防反灌 |
| FAST-C | CC Source/方向、SS Mux、预算内的电流宣告、独立限流/过流反馈 |
| A1/A2/KBD | 独立端口电源开关、过流反馈和正确USB供电行为；KBD公头CC与翻转接法需真实组件核对 |
| P4 DATA | 与主机上行完全分离，USB2 D±、SS TX±/RX±、地/屏蔽及下游VBUS参考；空置不能影响其他口 |
| MAG-L/R | 低功耗分路、断开释放、总线隔离；同地址附件同时接入不能直接并到触控I²C |
| Dock CTRL | 掉电不经GPIO钳位反向供电；DET/INT、电压域和I²C/UART选型待定，不占用已用GPIO |

## 4. 底部Dock对接：三分区，不使用八点MAG

本轮形成有尺寸的**空间研究区**：Core底部后侧，X=+36～+84、Y=+5～+23，总48×18。DATA为28×18；PWR为16×8；CTRL为16×8，见[底视与侧剖图](../design/drawings/dock-interface-r3-1.svg)。不是连接器焊盘、开孔或已验算布线区。

DATA连接器应提供USB2差分对、SuperSpeed收发差分对、连续地回流/屏蔽以及VBUS参考。PWR单独传Dock→Core受保护5V/GND与检测；CTRL管理信号不能当作USB数据。DATA端口VBUS与Dock大电流回供是不同网络，必须避免经P4 VBUS或CTRL反向给电脑/形成循环供电。

Samtec QSH/QTH带地平面的高速板间连接器可研究，厂商列有多种配对和高度；不能由系列最高速率推断任意料号、任意堆叠或本机10Gbps链路已合规。[Samtec QSH官方资料](https://www.samtec.com/products/qsh)。PWR需另核对连续电流、并联降额、温升及接触顺序；普通小信号连接器不按总功率选用。具体配对料号仍TBD，空间研究可能随真实器件扩大。

侧剖仅研究Core PCB底面Z=6.4与Dock PCB顶面Z=−1.6之间8mm；Core底板Z=0～2.4穿越区必须在配对连接器定型后再开孔。Dock外壳高度20mm、顶面Z=−1只是研究包络，不是尺寸冻结或真实PD模块装配证明。装配定位必须先接合、最后由螺丝/结构锁定受力，连接器不承受整机剪切力。

## 5. 机械干涉与附件

- 中央同心轴线保留；实心EC11不能占屏体中心。侧置编码器传动与环形磁/光学检测均待选，先确定屏幕背板/FPC、导向和行程，再设计真实轴承/齿轮。
- Core旧孔(±104,±28)、MAG端面±114、FAST(-114,+17)与Dock候选区在二维名义边界上不重叠；这只是边界检查，不能替代连接器后伸、屏蔽壳、焊尾、插拔线束与3D公差。
- 四键外端±84、两端30mm留白、主体键高0.3mm、右侧五键高度9mm保留。长键仍需多点支撑。
- 右侧一字五键与前部104×22×8横条保持；K5/Fn为附件功能目标，未改当前四键固件。Slider有效90～96mm为目标；MCP23017/AT42QT2160类器件仅候选，电极、地址、INT及线性度需测。
- Dock叠装会改变总高和手感；不通过加高Core或挪动环屏来掩盖干涉。Rev A默认不装Dock，原HTML只在主机展开时显示可选包络与分区。

## 本轮结论与放行门槛

WP0迁移和WP1/WP2资料评审可完成；**Rev A电气/布局放行仍阻塞**于Core单线峰值功耗、Hub总线/自供电配置、具体CC/Mux/保护、Dock真实配对器件和中央传动。未执行KiCad ERC/DRC、OpenSCAD实体编译、USB眼图/合规、插拔/热测或烧录。先做台架测量与连接器选型，再通过Konnect建立真实电气工程，不能把旧被动线束载板改名即称R3.1原生主板。
