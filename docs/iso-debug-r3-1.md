# R3.1 右后独立 ISO／DEBUG USB-A：工程决定与实现路线

状态：**产品位置与功能目标确定，电路、开孔、料号和保护能力未验证。** 本文是 R3.1 的新增决定；[原 R3.1 交接](R3_1_CODEX_HANDOFF.md)和已实测主体固件继续保留。

**2026-11-02 首版范围收敛：**以正常烧录、串口、插拔和常见短路后可恢复为目标。首版必需的是独立 USB2 下游、USB2 数据隔离、隔离 5V、隔离侧集成限流/短路/反灌/软启动保护、插座侧数据 ESD、必要去耦及本地故障指示。精确电压/电流测量、跨域 I²C 遥测、电脑端 AI 自动控制留为预留功能，不作为首版原理图必装。见[首版连接原理图](../design/drawings/iso-debug-minimal-schematic-r3-1.svg)及[结构视图](../design/visualization/iso-debug-anatomy.html)。这两份是工程设计视图，尚未形成 KiCad 引脚级网表。

**2026-11-02 本轮执行范围：**先确定原理图层次页和器件功能块的位置，见[原理图摆位表](iso-debug-schematic-placement-r3-1.md)与[A3摆位视图](../design/drawings/iso-debug-schematic-placement-r3-1.svg)。本轮不画导线、不做 PCB；上面的连接图仅供后续连线参考。

## 1. 接口与拓扑

背部从左到右为 A1、A2、PC-C、ISO／DEBUG。PC-C 仍是唯一电脑上行；A1/A2、左侧 FAST-C、KBD、ESP32 CTRL、底部 P4 Dock DATA、两侧 MAG 和全部交互模块不改用途。外壳 228×76 mm、PCB 216×64×1.6 mm 仍只是候选包络。

| 接口 | X 候选 mm | 状态 |
| --- | ---: | --- |
| A1 / A2 | −91 / −64 | 原位置保留 |
| PC-C | +64 | 从 +91 向内移；开孔/焊盘待实际封装 |
| ISO／DEBUG USB-A | +91 | 最右侧；USB 2.0 至多 480 Mbps 设计目标 |

现有 USB7206C 候选的 P1～P6 已满。**优先验证的第七路径**：P6 明确接一个自启动的 USB 2.0 双下游 Hub；其一仍接 ESP32 CTRL（原功能），另一经 USB 2.0 数据隔离器接 ISO 口。不得把一对 D+/D− 并接两设备；USB2512B 是双下游候选，并非已选定器件。要验证 P6 多一级 Hub 后 CTRL 与隔离调试设备同时枚举、Hub 复位独立性、USB 电流报告与悬挂状态。[Microchip USB2512B](https://www.microchip.com/en-us/product/USB2512B)

```text
PC-C（唯一上行） → Core Hub ┬─ P1 A1 / P2 A2 / P3 FAST-C
                          ├─ P4 Dock DATA / P5 KBD
                          └─ P6 USB2 双下游 Hub ┬─ ESP32 CTRL（原功能）
                                                └─ USB2 数据隔离 → ISO USB-A
```

若 P6 级联不能同时满足供电、枚举和装配，再重新评估更多下游口的主 Hub；不得删减原 P1～P6 功能。USB 2.0 Hub、隔离器和新增开发板电源会增加 Core 自身负载；没有 Dock 时 ISO 口的可用电流取决于电脑实际宣告的预算，**不承诺 500 mA**，无足够余量时硬件保持该口关闭并报“电力不足”。Dock 仅能经原单向电源选择增强供电，不能形成第二上行或向电脑反灌。供电预算必须计入隔离 DC/DC 的输入损失、启动浪涌和所有原负载。

## 2. 两个电域与故障路径

[隔离结构示意图](../design/drawings/iso-debug-isolation-section-r3-1.svg)展示两个电域和独立机械固定关系；图中器件块只表达职责，尚未完成电路连接与隔离等级设计。

```text
Core 5V ── 输入保护／使能 ── 隔离 DC/DC ── ISO_5V ── 硬件限流/过压切断 ── ISO USB-A VBUS
Core USB2 D± ───────────────── USB2 隔离器 ───────────────────────── ISO USB-A D±
ISO 侧保护 FLT/PG ───────────── 本地 LED〔按器件输出特性接线〕
Core_GND ║ 物理爬电与绝缘边界 ║ ISO_GND → ISO USB-A GND
```

隔离口 GND 不接 Core GND。USB-A 金属壳、固定件和外壳接地方式必须按所选插座、EMC 和实际隔离等级设计；不能靠贴一层胶带就宣称绝缘。若被测板另接普通 USB、示波器地或其他共地线，整条调试回路的隔离会被绕过。电源异常由**独立硬件**限制或锁断；AI 和 ESP32 只负责读取、记录、请求复位，不得覆盖硬件阈值。端口允许复位时应先清除故障条件，再由受控动作恢复；异常下反复自动重试不是默认行为。

首版故障指示由隔离侧保护芯片的 FLT/PG 驱动隔离侧指示灯，不能把 FLT/PG 直接拉到 Core GPIO。若后续要求圆屏或电脑读取故障，再加入单路数字隔离或隔离侧采集。精确电流/电压采样、I²C 隔离和 AI 自动控制均列为后续选装，不能把没有采样电路的估算值写成真实测量。

## 3. 候选器件、材料和责任

具体数量、封装、占板面积和价格在电源预算与选型后冻结。[候选 BOM](../hardware/electronics/iso-debug-candidate-bom.csv)逐项列出首版必需和后续预留；这里的链接仅证明器件功能，**不证明已适配整机**。

| 功能 | 首选研究对象 | 必须确认 |
| --- | --- | --- |
| P6 一分二 | [USB2512B](https://www.microchip.com/en-us/product/USB2512B) | 自启动配置、12/480 Mbps 兼容、功耗和原 CTRL 稳定性 |
| Core 侧逻辑供电 | 复用经预算核准的 3V3_CORE，或新增局部稳压器 | USB2 Hub 与隔离器 Core 侧所需电流、上电顺序和去耦 |
| USB 数据隔离 | [ADuM3165](https://www.analog.com/en/products/ADUM3165.html)；参考 [CN0550](https://www.analog.com/en/resources/reference-designs/circuits-from-the-lab/cn0550.html) | 1.5/12/480 Mbps、外部时钟、两侧供电及 USB 眼图；不能把它当 10 Gbps 隔离器 |
| 5→5V 隔离电源 | [MORNSUN VRB0505S-5WR3](https://www.mornsun.cn/index/index/downpdf/pdf/VRB0505S-5WR3.pdf/name/VRB0505S-5WR3.html) 等额定 5W 候选 | 厂商、封装、输入峰值约 1.4A、热和 Core 单线预算；**不支持热插拔**，不可直接让插拔冲击打到模块输入 |
| 输入软启动与断电 | 受保护的输入开关，型号待定 | 隔离 DC/DC 启动浪涌不得拉低 Core 或违反上行电流预算 |
| 输出硬件保护 | [TPS25947](https://www.ti.com/product/TPS25947) 家族 | 按具体子型号选限流/过压/锁断/FLT，阈值与被测板和 DC/DC 额定相配 |
| 本地故障提示 | 电阻＋LED，由保护芯片故障脚驱动 | 电平、上拉与失电默认状态按最终后缀核对；提示灯在 ISO 域 |
| 后续遥测 | [INA238](https://www.ti.com/product/INA238)、[ISO1640](https://www.ti.com/product/ISO1640)、[ADuM1201](https://www.analog.com/en/products/adum1201.html) | 首版不装；确需电脑读取测量/故障时再加 |
| 时钟和无源件 | ADuM3165 高速时钟/晶体、Hub 配置与去耦，型号待定 | 根据最终芯片数据手册决定参数与所在电域；高速隔离器需要时钟参考 |
| 插座与绝缘 | USB-A 2.0 母座、绝缘座/套、阻燃塑料隔板、独立固定件 | 选定插座 3D 与屏蔽/爬电方案后定准确料号及壁厚 |

上表的 5W 电源**是空间与供电研究对象，不是承诺 ISO 口输出 5W**。在无 Dock 的 Core 上，其满载输入就可能吃掉约 1.4A，必须先测电脑 CC、Core 自耗与原外设需求。若单线预算不够，应降低 ISO 模式负载上限或只在满足条件时启用，不能擅自将 Dock 变成开机必需品。

TPS25947 家族的可调限流下限为 0.5A；如果实测无 Dock 预算要求更低的硬件限流点，必须换用适合小电流的保护器件，不能仅靠 ESP32 软件限制来冒充硬件门限。隔离 DC/DC 的认证状态也须按实际采购批次和目标市场重新核验；此处没有作安规承诺。[TI器件参数](https://www.ti.com/product/TPS25947)。

## 4. 机械约束：现有右端触觉马达会冲突

[右后端口图](../design/drawings/iso-debug-rear-study-r3-1.svg)使用统一坐标，仅是投影研究。ISO 中心 +91 与 [7 Plus 马达包络](../hardware/enclosure/haptic-reservation-r3-1.json)在 X 上直接重叠。马达右侧预留 X=85.5～100.5、Y=−30～+24、Z=9.5～15.5；USB-A 插座后壁到内腔的实际深度尚未选定，若它跨入 Y≤24 且高度重叠，就必须重新分层/移动马达或调整插座形态。右后安装孔 (+104,+28) 也邻近 ISO 插座尾部和固定柱。不能只看前面板开孔的 27mm 中心距就说装得下。

现按用户决定优先在现有 `Pc-Hub` 主工程内研究“右后短尾/沉板 USB-A＋主板局部隔离区”：以绝缘分界槽隔开 Core 与 ISO 域；隔离侧器件靠插座，绝缘 DC/DC/隔离器跨边界，USB2 Hub 放 Core 域。后壁绝缘套、独立固定件与止推结构承担插拔力，焊脚和隔离槽不承力。必须用所选 USB-A、PC-C、马达、孔柱、屏蔽壳和线缆实体模型做 3D 干涉与 5° 后壁厚度检查；必要时修改右马达托架，但保持两端顶面留白、MAG 座和壳体外形。清楚标注外露插头的插拔方向及手指空间。

PCB 上跨隔离边界的槽、爬电/电气间隙、焊盘、过孔、金属安装件和屏蔽返回按最终隔离目标及器件资料核算；**本文件没有指定一个可用于安规宣称的最小槽宽**。ISO 区域下方的 7 Plus 马达和柔性线不能跨越隔离槽或把两地桥接。A1/A2/FAST/PC-C 的 USB3 差分对仍要重新评估布局与信号完整性。

## 5. 软件与验证次序

首版电脑端可用 ESP-IDF 构建/烧录/串口日志与 USB 枚举记录做 AI 辅助分析；本地故障灯只供现场观察，没有跨域回传，电脑端不能据此声称读到了电压、电流或 FLT。后续装配采样器及隔离通信后，才可将真实测量和故障事件交给电脑端。无须 AI 芯片；断电/恢复/重烧录控制仍需独立设计和验证。ESP32 固件、既有 GPIO 和运行镜像当前不改。

1. 先用 USB2512B 与 ADuM3165 评估板验证 P6→CTRL+ISO 两设备同时枚举及断连恢复；保持无 Dock 工作。
2. 在可限流台架电源上测 Core 原系统、ISO 模块空载/启动/不同开发板负载，建立 PC CC 和 Dock 两种预算；不按模块标称功率替代整机测量。
3. 定插座和隔离电源封装，用 3D 模型检查右马达、后孔、后壁及全部插头；冻结 X/Y/Z 后才设计开孔。
4. 在现有 `Pc-Hub` 主工程内加入隔离原理图页，核对两地、电源保护、网络标签和测试点；完成 ERC 与 USB2 兼容验证。本轮不绘制 PCB，布局和 DRC 在后续阶段进行。
5. 对实物分别测试烧录、串口、重连、短路/过流锁断及恢复、Dock 插拔、无旁路共地；再把真实结果写入验收记录。

当前结论：**决定新增接口，不等于已具备保护功能。** ISO 口不作为普通高速 SSD 口；装板/制造文件和测试结果待以上工作完成。
