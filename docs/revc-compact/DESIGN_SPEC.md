# PC-Hub RevC Compact 实施基准

2026-11-25 · 设计候选 · 制造未放行

本页根据用户指定的 RevC Compact v0.1 和现行 `Keyboard_as_PC-Hub` 工程更新。附件的功能取舍进入 Compact 产品要求，标为候选或待验证的拓扑、器件和尺寸用于下一轮工程验证。附件提供的 11 月 23 日 PCB 数据是历史取证。现行 RevC 应从下列保存板继续，Compact 改板单独维护。旧产品交接与检查记录见 [RevC 文档](../revc/README.md)。

最新模块位置、板外固定与母座决定见 [模块布局与母座](MODULE_LAYOUT.md)、[线束表](HARNESS_CONTRACT.csv)和[安装坐标表](MODULE_PLACEMENT.csv)。

## 产品要求差异

| 项目 | 原 RevC 要求或当前实现 | Compact 要求与实施决定 |
| --- | --- | --- |
| 尺寸与外形 | 外壳约 228 × 76 mm，整板 216 × 64 mm，设计厚度 1.6 mm | 中央电路区以约 120 × 40 mm 为压缩目标。保留四周局部伸出，两种板形并行评估，外壳与最终板厚均待签核。 |
| 霍尔和 RGB | 旧机械文档曾列对称候选区。保存板已布四霍尔、ADC 和四 RGB | 四霍尔保留真实锚点。四 RGB 先按现位继承，导光验证后再决定是否迁移。U25 的真实偏位优先由磁铁位置和行程匹配处理。 |
| 波轮和输入 | SWJ1 三路已布到 GPIO38/40/41。当前 `deck-ui` 仍读 42/41/40/38 数字键 | 取消 SWJ1 实体。录音、静音与 Agent 通知由屏幕处理。Compact 固件切换四路 ADS1015，GPIO42 专用于 RGB_EN。GPIO38 为独立总禁用候选，40/41 暂无新分配。 |
| 高速 Hub | 原 RevC 已以 USB7206C 为主 Hub 方向，板上尚无该芯片的完整电路 | 唯一 PC-C 上行，A1、A2、FAST-C 各有 USB 3.2 Gen 2 10 Gbps 链路目标，三口共享上行。三口各保留 USB2 兼容数据。 |
| 键盘与 ESP32 | 保存板 JB1 使用键盘 P5 USB2 网络，内部 USB 仍有原型接头 JU1 | CC64-RGB 经 Hub 直通电脑。ESP32 独立枚举为 HID 和控制接口。浮动公头的 CC、VBUS、插合行程和应力释放仍需实物验证。 |
| 右后 ISO-A | 旧方向为 USB2512B 分支加 U102 ADuM3165。当前 U102 和 J101 在板 | 双 CH318T 是替代候选，主侧本地端口拟连接 ESP32，隔离侧驱动唯一 ISO-A，目标 480 Mbps。验证双芯片、耦合、隔离供电和枚举后再退役旧路径。 |
| I²C 复用 | U3 TCA9543A 0x70 给左右马达，U6 TCA9546A 0x71 的 CH1 给右 MAG | 合并候选为 U6 CH0 左马达、CH1 MAG、CH2 右马达、CH3 备用。两颗同址 DRV2605L 使用序列化通道访问。验证合并与故障恢复后才移除 U3。 |
| EC56、圆屏与中心下压 | EC56 已在原 RevC 选型方向中，旧方案优先考虑主板固定。当前 JE1 为原型口，JS1 共享 GPIO39 | EC56 优先由独立支架承力，A/B/COM 接入主板。圆屏独立托架，GPIO39 只承担一次独立下压。保留实物已点亮的 GH5＋GH4 线。板端现有 JL1 为六路 QSPI，原理图改接前完成逐针实测。 |
| 右 MAG | 左 MAG 已退役。JG2 为右 MAG GH8，已有供电限流、I²C 缓冲与板面保护 | 保留右端，优先 GH8 单头开口线接独立固定的 CX2.84-8P。外部配对次序、插拔镜像、尺寸及孔位待实际订货变体验证。 |
| 触觉和麦克风 | 双马达驱动及输出已经在板。INMP441 用 JM1 | 两只 iPhone 7 或 7 Plus Taptic 板外装配，各用 GH2。INMP441 成品模块经 GH6 后装，保留独立声孔、短 I²S 回流与录音期间振动抑制。 |
| 电源、Dock 与装配 | 可选 Dock，原型 JPOWER1。旧产品目标为 PCBA 170–180 元、整机上限 250 元，不含键盘/Dock | 单 PC 上行，Dock 电源须有防反灌和受控切换。细间距芯片及板端座由 SMT，预制线和模块后装。附件提到首批 300 元压价情境，首批订单开销与旧单台整机口径分开列账。 |

## 当前保存板核验

- 工程入口为 [Pc-Hub_RevB.kicad_pro](../../hardware/pcb/sources/revc/Pc-Hub_RevB.kicad_pro)。附件 `9a5b0690…` 与当前 PCB SHA-256 `178c878e83ca023ef502227162fd40ebc81542dd659845d58e9926f78bac59e8` 为不同保存版本。使用 KiCad 10.0.7 读取当前保存文件，得到 157 个封装、566 个焊盘、253 个过孔、988 段 F.Cu 和 595 段 B.Cu 铜线。附件与现行板的 157 个封装位号、安装面和 XY 逐项一致，566 个焊盘编号与网络逐项一致。铜线段数相同只表明数量一致。
- JH1、JH2、R101 的当前 PCB DNP 属性已设。JM1 的 PCB Value 为 `INMP441 MICROPHONE INTERFACE`，DNP 关闭。JPOWER1 的 Value 为 `BENCH_5V_DNP`，当前 PCB DNP 属性仍关闭，原型供电暂保留。SWJ1、U3、U102 仍在现行板上，USB7206C 与 CH318T 尚未落板。
- 用 KiCad CLI 对当前保存文件重跑检查。DRC 321 项含 12 项钻孔错误和 309 项警告，另有 80 项未连接。94 项图板一致性差异含 91 项字段不符、2 项缺封装、1 项网络冲突。ERC 为 2 项电源脚无驱动错误及 7 项警告。结果属于当前完整 RevC 板。制造放行还需要新板自身的 ERC、DRC、连通、3D 干涉、寿命、USB 通信、实测功耗和实际报价，以及高速 SI、隔离和温升证据。

## 紧凑布局

| 键 | 霍尔器件 F 面，产品 XY mm | RGB F 面，产品 XY mm |
| --- | --- | --- |
| K1 左上 | U23 (−65, +18) | D20 (−60, +18) |
| K2 右上 | U24 (+65, +18) | D21 (+60, +18) |
| K3 右下 | U25 (+69.5, −25) | D22 (+60.5, −24.5) |
| K4 左下 | U26 (−65, −18) | D23 (−60, −18) |

当前产品基准为圆屏旋转轴在底壳基准面上的投影，+X 向右，+Y 向后。保存板变换为 `Xk=150+X`、`Yk=100−Y`。新板首先锁定以上产品锚点，再单独记录与新 KiCad 原点的变换。当前 XY 是封装锚点，霍尔有效感应点和光学中心需单独测量。

1. **一块四层主板，外设走线束。** 中央密集电路区约 120 × 40 mm，主板用同一片异形外框覆盖原四霍尔和四 RGB。主板后缘从左到右保留 FAST-C、A1、A2、PC-C、ISO-A，MAG 固定在最右端面。圆屏、EC56、双马达、麦克风和浮动键盘公头各自固定并接线到主板。
2. **按实物和原按键坐标收外框。** 四霍尔中心外接框为 134.5 × 43 mm。若要求外接框绕产品原点对称，仅锚点就需要 139 × 50 mm。实际边界还需加封装、铜边净距、支撑、USB 插头扫掠及加工余量。板厂核价使用实际外接框。

EC56 订货型号、固定孔、Z 与同心公差，磁吸孔位与触点配合面，浮动公头行程与力，以及新 PCB 外形均待定。既有 EC56 目录约 Ø44 与 Ø44.32 原型圆屏的名义配合需看实际截面。圆屏上置方案优先检查能否避开同一高度的干涉。[Soundwell EC56 产品页](https://www.soundwell-cn.com/en/EC56-HA1%20Ring%20Encoder/540.html)

保留四层作为候选架构，L2 主域参考面连续并保持独立 ISO_GND，L3 分配电源及可验证回流。PC-C 与 FAST-C 分别完成各自角色、CC、翻转和供电控制设计。SuperSpeed 差分对以板厂实际上架叠层求 90 Ω 几何，参考面和过孔按实际回流审核。订购前将 U1 的 0.20 mm 钻孔方案与制造能力、模块焊盘和项目 0.30 mm 规则一起复核。

## 实施顺序与通过条件

1. 采用 [USB 端口预算](USB_PORT_BUDGET.md)做板级分配。优先验证 P6 上的 CH318T-A 同时服务 ESP32 与隔离侧、P5 键盘独立枚举以及 P4 Dock 行为。完成 PC-C / FAST-C / 键盘的 CC、过流与 VBUS 电源预算后，再锁原理图。
2. 按 [接口核对表](PINMAP.csv)完成屏线、EC56、MAG 和浮动公头；冻结实物料号、脚序、安装朝向、固定尺寸及公差。屏线先逐针导通并记录信号和接地点，再选择 GH6 保留、转接或新板重配。任一方案都须保留经验证的显示模式所需信号。
3. Compact 原理图中取消 SWJ1，并逐一处理原 GPIO 网络及上拉。GPIO38 优先用于独立总禁用，40/41 暂不分配。固件先切换四路 ADS1015 和 GPIO42 RGB_EN，继承中心按压和旋钮 PCNT，接着验证 K1–K4、磁场阈值/回差、失联释放、每档计数及录音期间双马达静音。Agent 审批以请求 ID、会话、来源和期限验证，失联或过期清除待决状态。屏幕录音、静音和通知入口按新模块方案验证。
4. U6 合并时按目标支路统一选择与访问，马达命令结束恢复约定空闲掩码。CH0 和 CH2 不同时打开，MAG 故障、I²C 锁死、上电复位与 READY/INT 必须能恢复。保留 U8/U10 的功能和外接保护。验证后再签核 U3 退役以及调试座的测试点替代。[TI TCA9546A 数据表](https://www.ti.com/lit/ds/symlink/tca9546a.pdf)
5. 完成 Compact 单板原理图及母座契约。外框覆盖四霍尔、四 RGB、必要板边净距与端口包络。随后进行真实布线、重填、保存读回，复跑 ERC、DRC、图板比对、逐端连通及隔离边界核验。按板上 SMT、板外部件、线束和工装分表，使用本批真实 JLC 报价核算单台与首次订单。
