# RevC Compact 模块布局、线束与母座

2026-11-25 · Compact 首选实施方案 · 待样件验证

采用**一块四层主板，加线束连接现成外设**。主板承载核心电路、四霍尔和四 RGB。圆屏、EC56、下压开关、双马达、成品麦克风、磁吸头和键盘浮动公头由壳体或独立支架固定，再走线到主板。高速与隔离 USB 口保留板端直焊，插拔力由壳体支承和主板固定共同承担。

## 产品坐标与固定方式

圆屏轴为 XY (0,0)，+X 向右，+Y 向后。板上封装锚点与产品开口、线束母座及器件有效位置分别登记。下表中的旧候选坐标可供初轮装配摆放，最终 Z、安装孔和开口尺寸由实物决定。现行板依据为 `178c878e83ca023ef502227162fd40ebc81542dd659845d58e9926f78bac59e8`。

## 主板外框约束

| 主板区域 | 霍尔锚点 XY mm | RGB 锚点 XY mm |
| --- | --- | --- |
| 左 | U23 (−65,+18)，U26 (−65,−18) | D20 (−60,+18)，D23 (−60,−18) |
| 右 | U24 (+65,+18)，U25 (+69.5,−25) | D21 (+60,+18)，D22 (+60.5,−24.5) |

四颗霍尔封装中心的外接框是 134.5 × 43 mm。中央密集区可按 120 × 40 mm 排布，整块 PCB 的实际外接框需覆盖封装边界、铜到板边、支撑和 USB 区。优先以一整片异形板轮廓保留四键位置，用局部伸出覆盖左右键区与右前 U25/D22。装配孔位和 Z 由壳体公差链确定。

旧双马达候选包络按 15 mm 横宽和 X ±93 mm 摆放，整体横向跨度约 201 mm。主板缩到中央后，机身宽度仍受这两个马达及其支架限制。若机身也要缩，允许马达沿 X 轴向内试摆，分别保持左右侧和长轴方向，并复查振动传播、磁干扰与拔插空间。[原 RevC 装配包络](../revc/ASSEMBLY.md)

主板排位先锁后沿五口相对顺序和中轴屏托，用实际插座机械图排出口间距。前沿中部布屏幕两座，JE1 放在其左侧的固定线槽内，JM1 放右前面向声孔，左右马达座面向各自外侧。JG2 沿右侧内缘布置且远离隔离屏障。线长沿实物固定槽测量并留拆装余量，插头、侧向弯线和解锁空间计入板边周围的包络。

保留现行 RGB 级联 **D20 → D21 → D22 → D23**，K1/K2/K3/K4 的串行索引依次为 0/1/2/3。四霍尔原通道接 ADS1015 AIN0–AIN3，模拟走线与参考地贴近，避开马达输出和开关电源。整机做 RGB 满亮、左右马达运行和 MAG 插拔并发的霍尔零点与误触测试。

## 母座改法

板端通常称为线对板 SMT 座，线束端为压接胶壳。主板在壳高受限且行线沿板面处优先用 JST GH 1.25 mm 侧插 SMT `SMxxB-GHS-TB`；连线从上方进入且插拔更便利处使用 `BMxxB-GHS-TBT` 顶插。标准压接胶壳为 `GHR-xxV-S`。两种板端座分别使用各自封装，并检查 Pin 1、线束出口、插头卡扣行程与焊接固定脚。JT1 和 JE1 都是 GH4，需分区布置并用不可交叉的线束卡槽与醒目标记防混插。配线按电气编号制作，逐根测通断。[JST GH 目录及安装图](https://www.jst-mfg.com/product/index.php?lang=2&series=105)

| 现有板端 | Compact 决定 |
| --- | --- |
| JL1 GH6、JT1 GH4 | 为线束保留两个座。JL1 优先 GH5，JT1 优先 GH4。记录样机工作显示模式，以及电源、回流、复位与数据线实际去向。若工作链路确需现行的六路信号，板端维持所需针数并使用已验证转接，Pin 1 到末针以通断为准。 |
| JE1 GH4、JS1 GH2 | JE1 GH4 整合 EC56 与独立下压，按已读回 Pin 1–4 保持 GND/A/B/PRESS。省下 JS1 插座，保留测点。 |
| JML1/JMR1 GH2、JM1 GH6、JG2 GH8 | 继承电气针序。为短线、安装和维修调整板内落点，优先侧插，只在实物出线方向需要时使用顶插。 |
| 总禁用 | 新 GH3 `GND / INPUT_ENABLE_N / NC`。首选开关在允许位置闭合至 GND，开路由主板上拉为禁用。验证 BOOT/复位独立、释放 HID、停止录音和审批、恢复后等待用户操作。 |
| JB1 / JU1 / JD1 / JP1 / JR1 / JH1 / JH2 / JPOWER1 | JB1 保留键盘数据与供电功能，量产座随合规 USB2 线束。JU1 在 ESP32 板内 USB 验证后转为调试测点。原型调试插座可通过共用测试夹具替代，保留低压 UART、BOOT、EN、5V/GND 以及马达差分调试可达性。 |
| PC-C / FAST-C / A1 / A2 / ISO-A / Dock | 前五个采用选定 USB 母座直焊，Dock 按约定速率与电流选专用连接器。高速铜线、Type-C 角色和过流保护仍需原理图闭合。[Microchip 硬件设计核对表](https://www.microchip.com/content/dam/mchp/documents/UNG/ProductDocuments/DesignChecklist/USB7206C-Hardware-Design-Checklist-DS00003336.pdf) |

## 功能与装配联调

- 四键按原 K1–K4 逻辑位置映射，固件使用 ADS1015 的 AIN0–AIN3，RGB 通过独立索引查表。保留既有五页、触摸和编码器，取消 SWJ1。首版用 Voice 页的按住/释放触控处理录音，用屏幕快捷项切换系统输出静音，用屏幕通知入口打开 Agent Center。这三个功能与 PC 侧 Companion 继续走 ESP32 独立 USB 设备接口，无需新增母座。沿用实体键盘自己的 USB2 路径。
- 检查主板与各外设之间的电源、地、信号通断和插头机械键位。屏幕用现有实物线束复现显示与触控后，再试主板候选母座。整机检查关机拆装、插拔载荷、键盘浮动、磁干扰、麦克风和壳体共振。最终需把线束长度、板框、安装孔、Z 和母座朝向回填到相应图纸。

[线束表](HARNESS_CONTRACT.csv)记录拟实施的逐针顺序。[安装坐标表](MODULE_PLACEMENT.csv)可直接作为 CAD 约束输入。存量板端数据单独见 [保存板针脚基线](PINMAP.csv)。两种板形、配合和走线完成评审后，以原理图、PCB 以及真实壳体装配验证锁定母座方向、线长、孔位及实际外形。
