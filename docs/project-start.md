# 桌面控制终端：设计实现起点

2026-10-13：继续使用现有库，不创建同用途 Desktop-Control-Hub。保留 R2 产品设计和全部历史内容；本次仅增加实施入口，没有构建或操作硬件。

## 独特目标

把圆屏、旋钮、宏键、触控条、四软键及外部事件变成可靠桌面操作。独立于视觉节点，物理输入应能完成基础操作。中央屏幕固定方向、外环旋转、独立按压、右侧五键和独立触控条的产品意图继续保留。

## 学习与实现顺序

| 阶段 | 学习/实现任务 | 产物与验收 |
| --- | --- | --- |
| P01 | 离线拆解现有设计，定义输入事件与UI状态 | 模块图、模拟输入表、禁用与释放用例；不操作板卡 |
| P02 | 屏幕、触摸、音频独立基线 | 获准后复测当前配置；历史成功不代替本次结果 |
| P03 | 编码器、宏键、HID | 上电禁用、显式触发、按下和释放、总禁用优先 |
| P04 | 多输入与手势事件整合 | 重复事件不重复执行，断连释放，三种Profile可切换 |
| P05 | Hub与结构集成 | 外设并发、供电、休眠恢复、尺寸干涉，逐项实测 |

以上阶段均等待后续实施。当前下一步只做 P01 的软件设计和用例。

## 外部项目边界

Edge-Gesture 产生手势事件，本库映射为HID动作；Event-Vision 和 Robotic-Gaze 不属于本产品的必需组件。WiFi-CSI 保持独立的无线学习目标。

eFlesh 软键先作为本库实验模块。只有形成独立的采集、标定和形变估计目标后再拆 Tactile-Interface，现阶段不重复建库。
