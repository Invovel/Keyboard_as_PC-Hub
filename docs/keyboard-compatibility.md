# Type-C键盘兼容性与PCB尺寸研究

日期：2026-10-09。仅使用厂商和标准组织资料。此表是代表性样本，不是市场份额排名，也不是实物兼容认证。未公开的数据留空，不根据宣传图片推算毫米值。

## 结论

取消与键盘等宽、边框完全对齐的约束。主机独立承力，键盘Type-C公头使用窄身、可调位置的接口小组件；主PCB尺寸由自身器件布局决定。键盘的端口位置只决定主机摆放方向、插头高度、颈部避让及伸出量，不能直接推出整张主PCB长宽。

“能插进去”还需要满足：键盘支持USB有线数据、插头完整接触、供电满足键盘需求、模式开关选有线，以及操作力不由母座承受。只充电的Type-C键盘仍需无线接收器/蓝牙。

## 对连接端的尺寸建议

以下是设计起点，不是对主流键盘测量后得到的覆盖范围：

| 参数 | 首轮建议 | 依据与限制 |
| --- | --- | --- |
| 进入凹槽的窄颈最大包络 | 宽9.5mm、高3.8mm | 对两个Wooting公布开口分别留出至少0.25mm侧向、0.16mm上下单边名义间隙；开口圆角、涂层、公差仍需检查 |
| 插头金属壳 | 使用有机械图纸的标准成品 | 不打印/拉长金属插接部分；遵守连接器配合尺寸 |
| 插头承载小板 | 初始布置约10×20mm，器件区留在凹槽外 | 选定公头焊脚及固定结构后修改，不能将这块10mm宽板直接塞入10mm开口 |
| 颈部避让试件 | 5/10/15mm三种肩部后退量 | 仅改变本机壳体到插头肩部的避让；不改变标准金属壳长度，不宣称覆盖所有凹槽深度 |
| 插头中心离桌高度 | 试验夹具暂覆盖5–25mm | 尚无足够公开高度数据，需实际键盘试插；调节后锁紧 |
| 插入方向 | 后向直插、左/右侧接两类组件 | 相同主板通过内部短线连接；侧接口键盘允许主机放侧面，无须对齐边框 |
| 受力 | 主机脚垫/支架独立承力 | 公头不承担主机重量、按旋钮力矩和线缆拉力 |

键盘支路初版用USB 2.0完整数据连接，使用受控差分阻抗的短板/成品短线；高速外设口不经过这个活动机构。若键盘本身还内置高速Hub，其扩展功能不在初版键盘支路保证范围内。

USB-IF定义的是连接器配合接口，不定义键盘外壳开口及母座离桌高度。[USB Type-C规范入口](https://www.usb.org/usb-type-cr-cable-and-connector-specification)

## 主PCB的尺寸决策

当前机械基准为[R2结构](../mechanical/dimensions-r2.md)：主机102×68，主板96×62×1.6；均为布局候选，不是加工图。主板内包含主控、Hub、供电、音频与连接管理，现有开发板及GPIO扩展板整板不承诺可装入。

早期100×80板框已被替代。背部3A+2C和侧面FAST必须采用真实连接器封装核对板边、插入深度和外部插头间距。62mm深度来自本机布局目标，不来自键盘端口统计；器件、排线、旋转/按压机构、高速走线或散热任何一项不满足，都必须复核板框，不牺牲净空。

主板不固定键盘公头的离桌高度；若将公头直接焊死在主板边缘，将失去本方案的主要适配能力。

## 下一轮获取精确数据的方法

每个实物记录：品牌/准确版本、接口所在面、母座中心到该面参考边的距离、离桌高度（支脚收起/打开）、凹槽宽/高/深、接口轴线角度、邻近开关空间、有线枚举结果。孔位坐标与整机外形分开记录。

[Keychron官方硬件目录](https://github.com/Keychron/Keychron-Keyboards-Hardware-Design)公开了多款模型的下载入口，本次已确认K2 Pro与Q1目录含外壳/整机STEP链接；**未完成这些STEP的导入测量**，因此不把它们当作已测量的尺寸证据。后续可据模型提取尺寸，再以实物试插确认版本差异。原始厂商模型不作为本项目原创模型发布。

量测数据表见[keyboard-port-survey.csv](../hardware/keyboard-port-survey.csv)，设计起始参数见[interface-parameters.json](../mechanical/interface-parameters.json)。
