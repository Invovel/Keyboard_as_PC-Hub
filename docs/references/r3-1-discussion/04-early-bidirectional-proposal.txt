# Keyboard as PC Hub：主件与磁吸扩展件双向供电架构

这次我建议对 R3 做一个比较重要的架构升级：

主件负责交互和控制，扩展件可以提供电力、USB 数据接口，甚至接管电脑上行连接。

这样既能满足你希望“主体独立使用时只有一根线”的要求，又能让磁吸扩展件成为真正有价值的功能模块，而不只是增加几个按钮。

但有一个关键点：供电方向可以双向，USB 数据链路不一定需要双向。 把供电、数据、控制分开设计，才能实现你想要的效果。

## 一、先明确新的整体思路

建议将设备分为三个独立但可以组合的功能：

主件 Core

ESP32、圆屏、旋钮、软键、HID 和基础 Hub

电源扩展 Power

PD 输入、降压、供电分配、功率监测

交互扩展 Input

五键模块、磁吸触控条、其他传感模块

我认为真正值得引入的概念是：

主件不一定是供电中心，但始终是交互中心。

无论供电来自电脑还是磁吸电源模块，用户都应该通过主件的圆屏和旋钮操作整机。

这就解决了你担心的“电源接口转移到扩展件之后，主件显示屏是否还能操作”的问题——只要主件的供电和控制总线持续工作，显示屏完全不需要跟随电源入口的位置移动。

## 二、四种实际使用模式

模式 A：只有主件

一根 USB-C 连接电脑，主件自身供电。圆屏、旋钮、四键、HID 运行，基础 USB 外设在供电预算内使用。

目标：最少线材、日常办公和键鼠控制。

模式 B：主件 + 交互扩展

电脑仍然只连接主件。磁吸五键与触控条从主件取电，输入事件发给 ESP32，并通过主件 HID 上传电脑。

目标：不增加对外线材，扩充操作能力。

模式 C：主件 + 磁吸电源扩展

电脑数据线仍连接主件，PD 适配器连接电源扩展件。扩展件通过磁吸电源连接为主件供电。

目标：扩充电力，支持高功耗存储设备和更多外设。

模式 D：扩展件作为电脑上行入口

电脑线连接数据扩展件，扩展件内部的 USB Hub 将电脑连接分配到主件 ESP32、键盘及其他外设。

目标：扩展件决定对外连接方式，主件继续负责整机交互。

模式 D 最有探索价值，但也最需要明确设计边界。

如果扩展件接电脑，而主件内部还有另一颗 Hub，就必须决定两颗 Hub 如何级联，或者通过受控 USB 数据切换器选择上行路径。不能把两个 USB 上行口直接并联。

## 三、两种供电来源怎么自动切换？

我推荐设计一条全机统一的受保护 5V 系统母线，但由独立电源路径管理器控制输入来源。

双输入供电与统一控制

功能示意，不代表可以直接把两路 5V 并在一起。输入必须分别具有符合电源角色的控制和反向电流阻断。

在正常条件下，我建议设置这样的优先级：

| 电源条件     | 控制策略                  |
| -------- | --------------------- |
| 只有电脑供电   | 使用电脑允许的功率，确保主件基础功能优先  |
| 磁吸电源模块连接 | 在确认输出能力后切换到扩展电源       |
| 外部电源突然移除 | 降低下游功率预算，再按受控路径切回电脑供电 |
| 两种电源同时存在 | 由电源路径管理器选择，不允许反灌      |
| 两种输入都断开  | 无电池方案下设备关闭            |

实际切换是否会重启，取决于供电切换速度、缓冲电容、负载变化和上游供电是否充足；若要求真正不断电，还需要进一步设计保持供电及负载卸载机制。

而且，如果磁吸模块内部接入 20V PD 适配器，我更建议在扩展模块内部完成 20V→5V 转换，再通过磁吸接口输出受保护 5V。不要让 20V 高压直接经过你原本用于五键和触控条的 8 个低压触点。

## 四、磁吸接口需要升级，而不是简单增加电源针脚

现有每端 8 触点方案适合五键、触控条等低功耗附件，但不应直接承担整机最大 46W 的供电。

例如，假设扩展件通过 5V 向主件传输全部 46W：

\\[ I=\frac{46W}{5V}=9.2A \\]

这意味着磁吸连接器、接触电阻、镀层、线束、保护电路、PCB 铜箔都必须按实际持续电流和温升设计。普通低电流弹簧触点不能直接认定可以承担 9.2A。

我建议把磁吸接口分成两种规格。

| 接口       | 用途           | 设计方式                   |
| -------- | ------------ | ---------------------- |
| MAG-L/R  | 五键、触控条、普通传感器 | 原有 8 触点低压低速接口          |
| MAG-PWR  | 电源扩展模块       | 独立大电流触点、GND、检测、温度和控制信号 |
| MAG-DATA | 可选高速数据扩展     | 专用高速连接器，不复用普通 8 触点     |

这样就不必让所有磁吸附件都采用昂贵的大电流、高速连接器。

推荐的供电磁吸模块结构

```
       电源扩展件                          主件
┌──────────────────┐              ┌─────────────────────┐
│ USB-C PD IN      │              │                     │
│       │          │              │   电源路径管理器     │
│ PD Sink 控制器   │              │          │          │
│       │          │              │       5V_SYS        │
│ 20V → 5V 降压   │              │          │          │
│       │          │              │  ESP32 / 屏幕 / Hub │
│ eFuse / 电流监测 │              │                     │
│       │          │              │                     │
│ MAG-PWR 输出保护 ├══大电流触点══╡  MAG-PWR 输入保护   │
│ DET / 状态通信   ├══低速控制线══╡  模块管理接口       │
└──────────────────┘              └─────────────────────┘
```

如果想做到主件可以供电给扩展件、扩展件也可以反过来供电给主件，应该使用双向电源路径架构，而不是让两边各自的 5V 输出始终直连。

USB-C 的供电角色和数据角色也不是同一个概念，USB PD 支持电源角色切换，但必须由协议控制器和配套功率开关实现。

不过这里有一个必须满足的硬件条件：

同时，圆屏可以控制的外部电源功能需要由扩展件提供控制与状态接口，例如：

- 查看各 USB 口的实测电流、供电状态。
- 控制指定端口的 5V 输出开关。
- 设置允许的端口功率策略。
- 显示外接 PD 适配器协商结果。
- 显示过流、过温、掉电故障。
- 对特定端口执行受控断电和恢复。

这才使圆屏真正成为桌面电源的控制界面。

## 六、我更推荐的三个结构方案

方案 A：主件集成 Hub，外接磁吸电源

实施最直接

主件保留现有 USB Hub 与电脑上行口，磁吸件只负责增强供电。

优点：不用跨磁吸接口传输 USB 10Gbps；主件始终可以独立与电脑通信。缺点：主件内部需要容纳 Hub 及较多 USB 接口。

方案 B：主件只有控制功能，扩展件承担 Hub 和供电

优点：主件更轻薄，Hub 与大电流电源集中在扩展件。缺点：拆掉 Hub 扩展件后，主件还需要另一条 USB HID 上行路径才能独立使用，且对接接口至少要具备供电与 USB2 数据能力。

方案 C：主件和扩展件都支持电脑上行，并自动选择连接路径

优点：使用方式最自由。缺点：需要 USB 上行选择与隔离、连接状态检测、角色处理和重新枚举机制，磁吸接点的高速信号设计也更复杂。

方案 C 的主要挑战不是 ESP32 软件，而是两个不同位置的电脑上行入口如何安全接入同一个 Hub。简单把两个 USB-C 口并在一起不可行；采用切换器也通常需要在切换时重新枚举，不能保证 U 盘写入过程无感切换。

## 七、进一步发散：把“电源扩展”和“数据扩展”做成两个等级

还有一个我认为更适合长期发展的方案：采用基础主件 + 交互磁吸接口 + 高功率扩展底座。

基础主件可以直接使用，底部或者后侧提供一个专用 Dock 接口；普通五键和触控条仍使用原来的低速磁吸接口。

建议的模块组合

功能结构构想：上层继续承担交互，下层承担可选供电或数据扩展。不是当前 R3 外壳的已验证机械设计。

这种方案有两个优势。

首先，主件无需为了高达 46W 的供电能力预留完整的大电流降压和散热空间，减少对中央屏幕、旋钮和软键结构的挤压。

其次，大功率扩展件可以具有更可靠的承力结构，不需要把所有供电电流与机械负载都压在侧面八个磁吸触点上。

还可以扩展出其他模块，例如电池供电模块、额外 USB 端口模块、环境传感模块或无线控制模块。电池模块需要另行设计电池保护、充放电管理及运输安全，不能直接沿用普通 PD 电源模块的电路。

## 八、我推荐的最终组合

综合你的 R3 外形、中央控制需求和减少线材的目标，我更推荐：

## 方案 A + 专用 Dock 扩展接口

主件保留 ESP32-S3、基础 USB Hub 与唯一默认电脑上行接口；磁吸电源扩展负责增强供电；更复杂的 USB 数据扩展通过独立 Dock 接口实现。

| 主件单独使用      | 一根电脑线，圆屏与 HID 正常运行 |
| ----------- | ------------------ |
| 接五键和触控条     | 磁吸供电与控制，不增加线材      |
| 接电源扩展件      | 电脑数据线 + 可选适配器线     |
| 升级 Dock 扩展件 | 可另外设计扩展件上行入口及切换机制  |
| 圆屏控制        | 所有模式始终由主件 ESP32 负责 |

在 PCB 设计上，应一次性预留三个不同等级的接口体系：原有低功耗 MAG、额定大电流 MAG-PWR，以及用于高级 Dock 的专用数据连接器。这样避免后期为了增加供电功能，把现有触控条接口推翻重做。

还有一个设计原则建议冻结：所有涉及过流、过温、PD 协商和电源选择的安全动作，都由专用硬件自主完成；ESP32 负责用户设置、策略和显示，不能成为电源保护生效的必要条件。

最终，你可以把这个产品发展成：

一个始终独立可用的桌面控制核心，加上按需求组合的电源、USB Hub、宏键与触控扩展系统。

这样保留了单线使用的简洁性，也允许某个扩展件承担额外的对外连接，而不会让整个产品被“必须只有一根线”这一条件限制。
