## 五键与横向Slider的实现目标

| 项目 | 当前目标，尚未实装 |
| --- | --- |
| 几何 | 五键112×76候选、原19.05间距和9mm外露高度；前部横条104×22×8，位置不变 |
| 有效区 | 长90～96、宽12～16，两端各4～7；不是把壳长104当成已测触摸长度 |
| 采样/分辨率 | 目标≥100Hz更新、至少8-bit位置；不是实测响应或256个稳定物理位置 |
| 默认映射建议 | K1撤销、K2复制、K3粘贴、K4 Profile、K5按住Fn；不修改主体四键的媒体映射 |
| Slider | 默认相对滑动；Fn选择第二层/可选绝对位置；抬手/松Fn/断开附件都清除保持状态 |
| 手势 | 单击/双击/滑动由后续ESP32输入逻辑处理；单指Slider不当作多点触控板 |
| 反馈 | 用Core圆屏显示实际操作/连接状态；没有主机回传时不伪造系统音量、歌曲位置或应用上下文 |

时间轴/绝对音量控制需要目标应用或电脑协议支持，不能仅发送普通媒体HID就宣称能精确定位歌曲。建议映射尚未写入现有固件，不影响已实测功能。

## 控制器收敛与原型门槛

MCP23017可作为五键扩展候选，AT42QT2160可作为单指Slider原型候选；均需确认地址、RESET/INT、供电域、保护和实际模块封装。左右同地址附件必须隔离，不能因为单个五键与Slider的地址不同就直接把两侧总线并联。

Microchip说明AT42QT2160的Slider可用2～8通道，数据手册给出沿条方向约5～7mm键宽的线性度建议。90～96mm有效区不能仅凭8-bit输出认定可实现；8段均分时约11.25～12mm，偏离该建议，需验证电极、覆盖层、噪声、端点和线性度。若不达标，重新选适合该长度的单指控制器/电极方案；不因此缩短横条、改竖条或扩大为多点项目。[官方产品](https://www.microchip.com/en-us/product/AT42QT2160)、[数据手册](https://ww1.microchip.com/downloads/en/DeviceDoc/Atmel-9502-AT42-QTouch-BSW-AT42QT2160_Datasheet.pdf)、[MCP23017资料](https://www.microchip.com/en-us/product/mcp23017)。

验证顺序：先五键按下/抬起/组合与掉线释放，再单条电极位置、目标长度/宽度的重复性与端点，最后Fn组合、更新率和手指到HID延迟。原型门槛未满足前不冻结附件PCB。

## 补强后的工程冻结门槛

1. Hub电源轨/复位按官方资料设计。特别核对USB7206C的启动I²C/SMBus配置：官方检查表说明检测到相应上拉时可等待外部配置，不能把它直接接到ESP32总线后声称自启动。[USB7206C硬件检查表](https://www.microchip.com/content/dam/mchp/documents/UNG/ProductDocuments/DesignChecklist/USB7206C-Hardware-Design-Checklist-DS00003336.pdf)。
2. Core单线启动/稳定峰值和端口预算实测；Dock插拔按总线/自供电状态限制负载并决定是否重枚举，不承诺SSD无中断。
3. 中央编码器与环屏/Z轴/FPC实际机构、USB座封装/开孔、底部专用DATA/PWR/CTRL配对件与承力锁定冻结。
4. 总禁用在Core前侧中部，具体开关/开孔仍待定；本轮只调整展示位置，不改变GPIO0运行映射。
5. 旧R3 `generate.py`入口已停用并返回非零，不再写回A3/POWER或KiCad；旧源文本留档。当前生成器只输出R3.1 JSON/SVG。
