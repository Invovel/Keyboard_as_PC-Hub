# 产品功能、散件验证与后续单板集成

日期：2026-10-09。本轮按用户要求先明确功能，用现有硬件和散件组装验证，再进行PCB集成。此轮不生成可下单Gerber，不把板框占位当成已完成PCB。

## 产品形态

独立主机＋右侧磁吸五键模块＋独立磁吸触控条；主机约5°操作面。中央圆屏保持显示方向，外圈旋钮只旋转，中央屏幕可触控和独立机械按压；周围四块独立eFlesh软键，左①④小、右②③加长，感应中心固定，彼此隔开，不能改成取消机械旋钮的连续软环。独立总禁用键放前侧。

原键盘经可调Type-C公头接入Hub。机壳无须等宽或贴齐键盘；支持独立承力、后向/侧向插接。无可用有线USB数据的键盘不能只靠公头完成输入连接。

## 功能与散件对应

| 功能 | 已有/需要补齐 | 散件阶段做到什么 | 通过后集成什么 |
| --- | --- | --- | --- |
| 本地主控与配置保存 | 保留N16R8和GPIO扩展板 | PSRAM、重启、配置读写稳定 | 首选同等容量ESP32-S3模组及必要电源/下载电路 |
| 圆屏UI | 保留TK015F5785_PB | 纯色、方向、页面、USB状态显示 | 屏幕连接座与固定孔，保留用户GPIO |
| 触摸输入 | 保留板载触控 | 扫描、坐标、页面点击，之后做圆屏鼠标页 | I²C连接及必要隔离；不虚构INT/RST |
| 音频反馈 | 保留MAX98357A和扬声器；补匹配2Pin转接线 | 启用/停用/确认短提示音，和屏幕并发 | 功放、电源去耦及扬声器连接座 |
| 旋钮旋转及按压 | 补编码器和独立按压机构 | 音量、滚动、菜单选择，短按确认 | 编码输入及机械机构；普通实心轴EC11只供台架验证 |
| 外围四软键 | eFlesh打印件、磁铁、磁传感参考板 | 四键按下/松开、屏幕对应位置提示、无串扰 | 按实际位置布置传感器；需要时保留可换小板 |
| 五个宏键 | 5轴、5帽、热插拔小板、MCP23017 | 每键可配置快捷键；按住/松开正常 | 五键板仍留在可拆模块内 |
| 触控条 | 补支持位置输出的触控条模块 | 增量音量/滚动，抬手停止 | 触控电极及控制器，仍属于分体模块 |
| 总禁用 | 补明确的独立按键 | 立即停止输入并释放已按键 | 主板直连输入，不依赖UI正常刷新 |
| 磁吸供电/信号 | 补两组配对连接器、支架及保护电路 | 先断电插拔，再验证掉线释放及恢复 | 统一接口、供电控制与总线隔离 |
| USB键鼠/媒体控制 | 复用N16R8原生USB | Keyboard/Mouse/Consumer HID | GPIO19/20原生USB连接，板上接口用途明确 |
| 键盘和外设Hub | 选独立供电、足够数据口的Hub | 键盘、主控、多外设同时枚举 | 后续将验证后的Hub功能区纳入主PCB |
| 高速外设 | 单独FAST接口 | 实测协商、吞吐、并发与掉盘 | 10Gbps通道及完整Type-C支持电路 |
| 视觉手势识别 | 可用XIAO ESP32-S3 Sense＋摄像头 | 本地静态手势识别，经ESP-NOW送事件 | 视觉节点保持独立，不挪用受保护CSI设备 |

显示页面至少包括首页、媒体、宏键、鼠标触摸板、设置。基础电脑操作走标准HID；无电脑回传程序时不能显示真实系统音量、歌曲信息或声称自动知道当前软件。

三种Profile：媒体（音量/播放/切歌）、演示（翻页/开始/退出/黑屏）、桌面（滚动/确认/快捷键）。K1–K5与四软键F1–F4分别可配置，停用/断联时释放全部保持键。

## 单板集成的边界

“集成到一张板”指主机中的主控、供电、音频、Hub和连接管理整合成主PCB。磁吸五键、触控条和远端视觉仍需自己的载板，否则无法物理拆分。接口公头可继续使用窄身小组件，由主板内部短线连接，这是适配不同键盘的必要结构余量。

在散件阶段不急于固定主板元件封装或生产板框；先用[R2的96×62mm候选占位](../mechanical/dimensions-r2.md)检查尺寸趋势。主板最终可能扩大，外壳同步参数化。现有开发板和GPIO扩展板保留用于调试，不要求把其整板外形塞进最终主机。

## 机械设计准备

现已确定[R2候选布局尺寸](../mechanical/dimensions-r2.md)，供下一步建模使用。图纸孔位与真实器件干涉仍需验证。

| 模型件 | 应保留的参数 | 何时定型 |
| --- | --- | --- |
| 主机上下壳 | 5°、PCB包络、接口开孔、壁厚、脚垫 | Hub/电源及主PCB布局完成后 |
| 中央圆屏及旋钮支架 | 屏幕PCB毫米尺寸、孔位、排线、旋转与按压行程 | 实测屏幕后；托架周边承力，不能直接顶压玻璃/屏背 |
| 四软键座 | 软键尺寸、限位、传感器距离、磁吸件间距 | 单键和四键串扰测试后 |
| 五键壳和触控条壳 | 19.05mm键距、独立接缝、触点防呆 | 对应小板和连接器定型后 |
| 可调公头座 | 高度、伸出量、方向、锁紧及应力释放 | 代表性键盘试插后 |

现阶段准备[参数文件](../mechanical/interface-parameters.json)，它不是完成的3D模型。最终交付仍应有可编辑CAD、STEP、分件STL、装配图以及匹配的PCB工程，但需在验证后的真实尺寸上制作。

## 分阶段验收

1. 按[当前接线](../hardware/current-wiring.md)复测已有四件套；不修改已占用11个GPIO。
2. 单独完成原生HID、机械旋钮、五键、触控条，再整合UI与总禁用。
3. 单个eFlesh小样→四个软键；每键至少30次独立测试，目标识别正确率≥95%。旋钮转动/按压、磁吸件靠近与扬声器工作不产生误键；指标为目标，未测量。
4. 接有源Hub，完成键盘直插和并发外设测试；测试供电压降、发热、电脑休眠与恢复。
5. 用可调夹具验证接口凹槽、母口高度、支脚位置；记录真实版本、尺寸和结果。只报告实际测试通过机型，不报凭空的覆盖率。
6. 汇总功耗、传感布局、连接器和尺寸后画集成原理图，再布板、ERC/DRC、装配干涉检查和打样复测。通过电气检查不等于高速信号或实物通过。

## 开源参考与保留原则

- [eFlesh](https://github.com/notvenky/eFlesh)：软结构、采集、标定和训练参考，仍需适配本机四软键；传感器不是仅打印就可用。
- [BlueKnob](https://github.com/joshuacant/BlueKnob)：圆屏及多媒体/触摸板交互参考，硬件与通信方式需调整。
- [FreeTouchDeck](https://github.com/DustinWatts/FreeTouchDeck)：触屏快捷操作与配置体验参考。
- [TinyUSB](https://github.com/hathach/tinyusb)：标准HID实现参考，与所用ESP-IDF版本配合验证。
- [ESP-DL](https://github.com/espressif/esp-dl)：本地视觉推理参考；电脑只做开发训练，不作为成品识别服务器。

原有Functions和STM32F103C8T6目录仅是旧方案/示例，不代表当前ESP32固件可用。旧预算、尺寸、PD说明及Hub端口数均不能直接复用为本次采购或接线依据。
