# RevC PCB 与机械接口 · 第一批

产品坐标 `X=Xk−150`、`Y=100−Yk`。正反面共用 XY，角度用 KiCad 原生值。圆屏轴线和底壳底面分别作 XY 和 Z 基准。PCB 外形 216 × 64 mm，设计厚度 1.6 mm。装配 Z 尚未冻结。机械源收到的线性距离使用 mm。

| 接口 | 保存板或候选位置 | 验收所需输入 |
|---|---|---|
| H1–H4 | 实际板孔中心 (±104,±28)，Ø2.4 | 螺丝装配轴、支柱顶面和公差 |
| SWJ1 | 实际锚点 (−102.9,0)，F.Cu，90°。两定位孔 (−103.9,±1.9)，Ø1.1 | 壳体开口、触发与回弹、外露量 |
| EC56 / 独立屏按压 | 产品中心 (0,0) 是设计基准。查到 EC560101X5A-HA1-000 / -001 两种安装图，均有约 Ø44 的中央标识，安装细节不同 | 按订货版批准图判定 Ø44 的实际配合特征。若为穿过屏外缘的通孔，则与 Ø44.32 屏有 0.32 mm 名义直径重叠。安装孔和 Z 留空 |
| 霍尔 | 矩阵的 (±65,±18) 是候选封装区域 | 磁场有效感应点相对封装锚点、逐键行程、温度/串扰与硬限位 |
| JL1 / JT1 | 当前锚点 (−20,−28) / (+20,−28) | 面板 FPC 与连接器实体配合面、回路和弯折高度 |
| J101 / 其余 USB 开口 | J101 锚点 (+91,+26.55)，F.Cu，180°。壳体配合面及其余 USB 开口未知 | 连接器数据图、插头扫掠、禁布及隔离实体边界 |
| JML1 / JMR1 | 实际锚点 (−67.5,−8) / (+76,−26)，F.Cu，0° | 两针 GH 线束方向、弯折、马达耳与驱动负载 |
| JM1 / 麦克风小板 | 主板锚点 (−42,−4)，F.Cu，0°。小板候选 (+68,−25) | 线束端头、声孔输入与贴合、装配 Z |
| JB1 / 浮动 KBD USB-C | JB1 锚点 (+47,+27)，F.Cu，0°。真实公头配合面未知 | CC64-RGB 实物、USB 插合路径、滑移/承力尺寸、双方向检查 |
| 右 MAG 线束座 / 壳体触点 | 板上 JG2 锚点 (+76.5,+6)，F.Cu，GH 8 针、1.25 mm 间距。外壳右侧触点组中心候选 (+114,0)，八触点、2.5 mm 间距 | 外部触点组件需壳体承力，从 JG2 通过线束接入。配合端子厂图、触点朝向、安装 Z、孔径和线束弯折待核实 |

完整保存板锚点见[器件字典](component_dictionary.json)。它登记原生板面及三维模型引用；无模型、模型未定位和实体高度未知时请留空。现有 [装配研究](ASSEMBLY.md)可用于候选包络对照。主地与隔离地单独审核，连接器源面、金属件和螺丝均须参加精确总装。

EC56 目录波形定义 A–C、B–C，两相每转 15 个脉冲，机械 30 个档位。现有 PCNT 软件每四个计数产生一个旋转事件。若验收要求每档一个事件，须按实物计数与停留态重新标定。独立屏幕的 GPIO39 不进入 EC56。 [厂方产品页与两个目录安装图](https://www.soundwell-cn.com/en/EC56-HA1%20Ring%20Encoder/540.html)
