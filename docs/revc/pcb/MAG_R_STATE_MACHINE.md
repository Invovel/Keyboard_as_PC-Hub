# MAG-R 状态机契约

候选固件契约，2026-11-24。GPIO13=DET，GPIO14=ENABLE，GPIO18=现有共享 INT/FAULT/READY。U6 地址 0x71，右侧 CH1。实际固件由固件工作线实施和验收。

| 状态 | 动作 | 转移 |
|---|---|---|
| OFF | ENABLE=0，关闭 U6 CH1，释放输入状态，禁止附件命令 | DET 稳定为低后进入 DEBOUNCE |
| DEBOUNCE | 候选去抖20ms，持续监测插入接触 | DET 回高返回 OFF，稳定低进入 POWER_WAIT |
| POWER_WAIT | ENABLE=1，观察供电与独立 READY。候选启动超时100ms | 供电异常进入 FAULT，READY 高进入 ENUMERATE。READY 独立监测未落地前此路径待验证 |
| ENUMERATE | 100kHz，开启 CH1，读取协议版本、设备ID、能力、五键及104mm触控条描述。未知型号拒绝功能命令 | 正确描述符进入 ACTIVE，NACK或格式错误进入 RECOVER |
| ACTIVE | INT 触发后有界读取事件序号、五键位图、触摸有效位/坐标及状态，并清除已处理IRQ。定期心跳，重复序号去重 | DET 回高立即拔出处理，通信超时或共享INT持续低超时进入 RECOVER，明确供电故障进入 FAULT |
| RECOVER | 停止附件事件，关闭 mux CH1，有限次数恢复。总线锁死时先允许缓冲器恢复，再检查上游总线 | 候选最多一次断电重启，成功重枚举，否则 FAULT |
| FAULT | ENABLE=0，CH1关闭，释放所有已按下键、触控和待执行动作，向主机上报原因 | 条件消失且明确重试或重新插入后回 DEBOUNCE |

DET 回高在任何状态优先处理，立即撤销使能、取消事务、清空事件并报告拔出。通信错误、主机失联或 Agent 审批失效时拒绝执行有副作用的动作。附件仅提供输入，主机权限检查继续负责动作批准。

上述20ms、100ms和一次重试为候选参数，须按真实触点弹跳、启动电流、附件固件时间和电源放电验证。READY 分离后，共享 GPIO18 仍不能区分附件 INT 低和 U8 FAULT 低。正常 IRQ 先读取并清除事件，建议候选单事务超时10ms、连续低超时30ms，失败后进入有界恢复及停电。故障原因只能推断，独立 FAULT 监测仍待实施。

100kHz 验收至少包含上电枚举、五键并发、触控全长、心跳、拔出期间事务、SDA/SCL拉低、短路、接触弹跳和主机失联。400kHz 另行测量线束电容、上升时间、低电平及错误率。状态保持 MAG_INTERFACE_NOT_VALIDATED。
