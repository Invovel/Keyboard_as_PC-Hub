# PC-Hub RevC 最终设计规范 / Codex Handoff

**2026-11-19 | 设计方向冻结，制造未放行 | 单一事实入口：本文件 + matrix_schema.json + matrix_numeric.json + component_dictionary.json**

## 0. 快速入口与执行规则

- `RevC_Interactive.html`：离线交互结构图，依矩阵绘制，含旧PCB真实坐标/走线与新布局、上下壳结构、圆屏/Agent 灯光演示。无需网络。
- `matrix_numeric.json` / `.csv`：无文字数据体矩阵；字段顺序见 schema。CSV 无表头，空值代表未知（不是0），JSON 为 null。组件 ID 与字典关联。旧板焊盘及线段独立存 `old_pcb_geometry.json`；旧数据不得覆盖本地最新 PCB。
- `component_dictionary.json`：每个 ID 的中文名称、型号、安装限制、旧板位号及来源信息。产品坐标以屏幕圆心为原点；单位 mm，角度 deg。X 正右，Y 正后（高侧），Z 自底壳底面向上。KiCad X=150+X，Y=100-Y；老封装转角保留原生 KiCad 值。B面依然用正视投影坐标，不自动镜像。
- **冻结的是功能、总体结构、设计意图，不是最终全部孔位/物理装配或生产售价。** 候选参数必须通过实测获得确认，未经 ERC、DRC、3D 干涉、SI/EMI、功率、寿命评估不得生成生产 Gerber。
- 禁止自动覆盖旧项目与用户最新本地 PCB/CAD；先备份，保存哈希与变更日志，按 RevC 独立分支实施。未冻结的 Hub/隔离器不得擅自降速或删功能。

## 4. 端口/布局/供电

后部 A1、A2、PC-C、ISO（中心候选X=-91,-64,+64,+91，Y=+38），左FAST-C(-114,+17)，左SWJ1，右MAG-R；最新MAG-L已删除。底部Dock DATA/PWR/CTRL预留48×18，候选板间距8；Core仅PC-C电脑上行，KBD USB2下游独立受控5V、Source CC、ESD/防反灌，Dock可选经P4下游数据并单向供5V，不与PC VBUS直接并联。右侧附件五键112×76/键距19.05、104×22×8横条维持原关系；非Core主板的一部分。总禁用前中(0,-38)候选，旧GPIO0启动绑带需检查。外接设备、键盘RGB和满载隔离供电不能假定同时运行。

### 功耗及预算（目标，不是实际测量）

早期日常661mA/峰值1565mA@5V预算不含ISO/外接USB，原RGB与数字键预算须增加/重新测量霍尔（名义20mA@3.3V及ADC）与WS2812C全白最坏60mA+逻辑。当前示例日常仍以约0.7A、峰值至少约1.6A作保守原型预留，不保证精确。实测键盘RGB满亮、两Taptic各自/同时、Wi-Fi发射、背光、Hub、ISO并发。USB默认500/900mA仅在设备配置/枚举允许条件下；USB-C依CC宣告1.5/3A，不能假定PD或电脑输出高压。500mA最低模式可能无法带键盘；900mA基础；1.5A日常受限；3A扩展仍按预算。硬件自主限流/短路与防反灌，MCU只执行策略与显示。录音期间两马达关闭；单侧短脉冲为默认，供电不足禁双马达峰值。保护优先保证主控/键盘及数据安全。

PCBA 170~180元，其他全部配件及外壳约50，整机220~230目标、250硬上限，顶盖≤10目标（不是新增50以外）；不含键盘/Dock。嘉立创完成QFN/细脚/主控、被动、USB及驱动、RGB/霍尔等关键件，编码器/屏/马达/麦克风小板/浮动公头及机械自行装。必须以真实BOM/CPL与嘉立创报价确认扩展料/双面/工程费/X-ray/批量分摊；此前175元方案不包含完整高速隔离成本，完整方案可能超预算。先做成本研究，不删除功能。

## 5. 固件与功能映射

**保留历史五页**：真实枚举 DECK_HOME、DECK_CLOCK、DECK_METRICS、DECK_SETTINGS、DECK_VOICE。历史默认顺时针语音、Codex、设置、Chrome；物理驱动顺时针1/4/3/2（源README）。旧PCB JK1/2/3/4标注的GPIO为42/41/40/38，与固件顺时针ID不能混作同一个命名空间；新矩阵的K1/2/3/4仅是左上/右上/右下/左下逻辑位置，启动前核对映射。历史四个96×79内容槽位于(32,82),(232,82),(32,195),(232,195)；主页点击显隐，设置可控边框并NVS持久化，过渡中不显示。Clock保留时间、日期、天气；Metrics保留系统指标并可增加USB/电源；Voice保留玻璃遮罩、波形(51点)与等待输入；Settings保留主题/绑定/边框并扩展RGB、Agent偏好。Agent Center通过下拨、通知点击进入，**作为子页面/覆盖层不替换历史五页**。历史手势：左边缘右滑Clock，右边缘左滑Metrics，上边缘下滑Voice，下边缘上滑Settings，反向回Home；保留原动画，新增覆盖层不得误触底层。

### 审批覆盖层：按键、RGB与触控统一状态机

| 位置 | 普通默认/可配置灯色 | 审批语义/颜色 |
|---|---|---|
| 左上 | 语音/蓝 | Apply/绿 |
| 右上 | Codex/紫 | Apply for Session/黄 |
| 左下 | Chrome/青（按历史顺时针语义，实际映射需核对） | Reject/红 |
| 右下 | 设置/橙 | Open/白 |

普通色为候选配置。任务完成/输入所需/异常：仅右下Open白，其余灭且禁用；退出覆盖恢复当前底层页面及按键映射。审批只按实际availableDecisions显示可用选项；Session二次确认，信息不足仅Open；Cancel与Reject不可混同；请求ID/会话ID/Agent来源/有效期/处理回执强绑定。请求变化、失效、断联、总禁用：撤销有效审批，灭灯/失效反馈；不接受重复旧请求，不能自动批准或盲目Enter。触控支持任务选择、滚动、详情、设置、简单选项；复杂输入跳电脑。Open定位真实项目/会话/审批（若适配器不支持精确定位，则明确仅打开应用）。

Companion Windows本地服务，USB原键盘/鼠标/多媒体HID保留，增加Vendor HID或验证端点后的CDC；语音选择USB Audio或专用音频传输。Codex App Server正式审批接口（commandExecution/requestApproval、fileChange/requestApproval、availableDecisions、serverRequest/resolved、item/completed），按版本验证。官方现成Codex桌面会话是否可接入尚未证明；不假装任意弹窗可控制。多Agent Adapter、通知队列、任务状态/INPUT_REQUIRED/异常/完成、Open应用跳转。真实执行权限留在主机。霍尔接近阈值必须由真实位移校准，按下/释放滞回、滤波、去抖、马达时段防假触发，禁止依颜色判定授权；触觉时序和按键抑制必须验证。录音开始前关闭两马达并确认振动衰减、不截断开头；录音内只用屏/RGB反馈。

## 6. 验收和实施顺序

1. 核对最新本地 PCB 哈希、收集实际屏及EC56厂图、CC64-RGB端口实物、双马达耳孔/线圈。检查冻结与候选值，不自动导入旧坐标覆盖。
2. 打印单区/四区弧形试件，实测按压力、位移、回弹、四区串扰、旋钮摩擦，硬限位承力；每键≥100000次，无裂纹/明显永久形变/误触、漂移超限，记录前后阈值。无法通过则启用真正鼠标微动+RGB或机械解耦，重新测外壳。顶盖取得真实打印报价。
3. 霍尔ADC实测电压-位移曲线、温漂、噪声和饱和；静态/动态双马达、磁吸附件热插拔、编码器、相邻键和Wi-Fi/USB干扰下无错误审批。若无稳定边界，禁用审批并重新布局。磁铁固定防脱。
4. 确定3D总装、接口中心/投影、马达与ISO和后孔冲突、音孔与键盘遮挡、供电与热、屏幕FPC、螺钉柱/铜区。对比录音无遮挡/透声网/单/双口，测干扰。顶壳先样件再总装。
5. 核主控/ADC/LED/Hub/CC/电源/ISO及原理图全部端点，完成GPIO表和BOM/CPL、实际报价；原理图 ERC、PCB DRC/焊盘/净距/爬电、四层参考地/阻抗/回流、USB枚举断连和满载测试。
6. 保留真实历史UI建立新固件分支，测试5页及覆盖状态、语音开始/结束/取消、四灯与输入、Open准确性、断联/过期/重复/会话授权、复合USB端点、总禁用。先软件模拟，不执行真实自动审批。
7. 最终保存真实四层叠加纯线路SVG/PNG、完整制板资料前的复核报告，记录实测功率/温升/成本/寿命。只有所有阻塞消除才允许制造放行。
