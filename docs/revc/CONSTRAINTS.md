# RevC 坐标和约束

- XY 原点为圆屏轴线，产品原点是该轴线与下壳底平面的交点。+X 向右，+Y 向后高侧，+Z 向上。距离单位 mm，产品 XY 朝向为从 +Z 俯视逆时针度数。
- 此保存板的 XY 变换为 `Xk = 150 + X`、`Yk = 100 − Y`。B 面按产品正视投影，与 F 面共用 XY。保留原生 KiCad 角度及面别字段；求可用的三维旋转时须标定相应封装的局部轴与安装面。
- PCB 焊盘、机械孔和锚点用 KiCad 原生读回及产品变换。Z 需要安装定位和平面基准，实测缺失即 `null`。封装锚点与标准插头、配合面、供应商外壳中心分别建记录。原理图 ERC 图纸坐标仅用于定位原理图。
- 矩阵状态 1 为旧板实测，2 为确认设计方向，3/4 为候选，5 未知，6 已替代，7 为当前保存板实测。物理值 `null` 表示未知，0 表示真零。历史/当前实测来自各自的源哈希，均不能作 RevC 已实施的证据。
- 新建/替换器件须写明精确料号、图纸版本、物理引脚到符号及焊盘映射、锚点定义和正反面。示意件保持区分。修改 KiCad 源通过 Konnect，并仅操作已验证绑定的工程。
- 保留交接冻结功能。实际 116 封装文件是 PCB 起点。严禁用 79 封装文件、旧接线/孔位或旧示意图刷回基线。RevC 使用一体径向开槽顶盖、Hall+独立 RGB、EC56、独立屏按压、下壳承力、左右马达、独立 MIC、标准长颈浮动 KBD 公头、右 MAG、单 PC-C 上行、完整 Hub/ISO、可选底 Dock。
- 线宽按真实制造叠层求解。主地与隔离地独立，USB 高速走线不跨隔离缝，参考面与回流位置按实际铜检查。每次 PCB 修改后由保存板输出正视四层铜线、真实焊盘、过孔和钻孔单张图，可隐藏大面积铜区的显示。报告留实际层、铜区及未连接情况。
- 寿命、实测功耗、嘉立创报价、ERC、DRC、USB 通信、精确三维干涉全部完成前保持制造未放行。
