PCB 与 PCB 详细沿用现有分工，前者负责电路和板级改动，后者负责布线、图表与验证。同一 KiCad 对象同一时段由单一负责人写入。现有总控继续管理冻结方向、接口冲突、合并与验收。外壳/主要设计保留原机械责任线，当前记录未核实其具体聊天标识。执行表是项目分派，聊天中的运行状态由各工作线回填。

每批工程改动在本地保存后同步更新矩阵、器件字典和变更记录，并标识前后 SHA、所触及 ID、坐标等级与验证证据。机械线先做候选机构模型及包络检查，实测数据到位后再冻结壳孔、器件坐标和机械结构。
