# RevC 执行计划与任务归属

| 顺序 | 责任线及承接 | 工作与交付 | 进入下一步的条件 |
|---|---|---|---|
| 0 | 系统总控 ·「嵌入式系统总控｜整体规划与任务承接」；PCB ·「PCB」「PCB详细」 | 固定 RevC 需求，锁定保存工程和审查结果 | 已完成。待各专业实物取证 |
| 1A | PCB · 由原 PCB 工作线继续 | 霍尔/LED/ADC/I²C/GPIO 台账；EC56、SWJ1 和屏物理引脚；双马达驱动、MIC 接口、KBD 受控 USB2/电源 | 精确订货料号与引脚映射、连接器实体边界、机械定位表 |
| 1B | 外壳和主要设计 · 原机械工作线 | 环形四键弹性试片、EC56/屏独立托架、承力下壳、双马达座、独立麦克风声道、浮动公头 | 先实验机构，出左右/剖面和公差，确认各候选坐标 |
| 2 | 外壳主责，PCB 交付模型，总控验收 | 同一产品坐标的精确三维总装；各键全行程、旋环、FPC、马达/ISO、音孔、键盘插拔及壳体干涉 | 支撑和电气避让共同签核，缺失包络留空 |
| 3 | PCB 继续同一工程 | 由 116 封装修复版派生 RevC，优先实现 1A；再完成 Hub、P6、KBD/端口保护、隔离、四层叠层及真实布线 | Konnect dry-run、保存读回、完整 ERC/DRC/图板一致性、断点明细和单张四层综合图 |
| 4 | 固件/主机 · 原 UI 与固件工作线 | 沿用五页，增加霍尔、灯、波轮、触觉、录音、Agent 覆盖及 USB 复合端点 | 主机模拟及真实 USB 样机验收，审批失效时默认禁用 |
| 5 | 系统总控收口，专业各自提交证据 | 每键 ≥10 万次、实测功耗、嘉立创 BOM/CPL 报价、ERC、DRC、USB 通信和精确三维干涉；附回流/SI/EMI、隔离与温升 | 所有门槛完成才制造放行 |

PCB 与 PCB 详细沿用现有分工，前者负责电路和板级改动，后者负责布线、图表与验证。同一 KiCad 对象同一时段由单一负责人写入。现有总控继续管理冻结方向、接口冲突、合并与验收。外壳/主要设计保留原机械责任线，当前记录未核实其具体聊天标识。执行表是项目分派，聊天中的运行状态由各工作线回填。

每批工程提交同时更新矩阵、器件字典、变更记录，并标识前后 SHA、所触及 ID、坐标等级与验证证据。基线实装前先做候选机构模型及包络检查；实测数据未到时禁止将候选壳孔、器件坐标或机械结构写成投板数据。
