# RevC 候选装配预检

可编辑 [OpenSCAD 装配研究](../../hardware/enclosure/sources/body-revc-study.scad)使用共同产品基准，先验证整体外形及基本相对位置。研究包含 228×76 圆角壳、外侧连续的一体顶盖、四条径向槽、三个候选顶部收音口、四孔 PCB 包络、低位下壳支撑研究、左右马达包络和屏/外环显示包络。RGB、霍尔、磁铁、限位结构、EC56 真实截面、声腔和浮动公头须继续取得零件坐标与装配 Z。

| 检查 | 结果 |
|---|---|
| 坡度闭合 | 76 × tan(5°) = 6.649 mm，前高 20 对应后高 26.649 mm |
| 外环与顶孔的 XY 同轴名义余隙 | (62 − 60)/2 = 1.0 mm。倾斜、旋转抖动、偏心及公差仍待真件验证 |
| PCB 与直壁二维余量 | (228−4.8−216)/2 = 3.6 mm；(76−4.8−64)/2 = 3.6 mm，独立于器件及接口突出 |
| 马达包络与 PCB 名义 Z | PCB 顶 8，包络底 9.5，名义差 1.5 mm。覆盖器件与支架的完整体积待核 |
| 右马达与 ISO | 马达包络 XY 为 [85.5,100.5]×[−30,24]；J101 实际锚点 (+91,+26.55)，平面距包络后缘 2.55 mm。任何向前突出超过 2.55 mm 且 Z 相交的零件都可能进入包络，须装配真件 |
| 麦克风与右马达 | 两候选包络 X 区间 [63,73] 与 [85.5,100.5] 相距 12.5 mm。组件 Z、声道、键盘遮挡待核 |
| 规格缺失 | KBD 端口 XYZ、EC56 精确几何、屏/线束活动体积、马达安装耳及收音结构 Z 均不足以完成三维干涉验收 |

本轮完成名义包络检查。另由保存板用 KiCad 导出本地 `outputs/pc-hub-revc-20261119/evidence/PCB_Product_XY.step`，使用 KiCad 原点 (150,100) 对应产品 XY (0,0)。导入外壳时仍需注册 PCB Z 和检查模型覆盖。116 个保存板封装中 58 个未注册三维模型，包括 J101、SWJ1、U1、U102。OpenSCAD 研究文件尚未由 CAD 引擎编译，Blender 实时连接不可用，精确运动、受力和干涉验收仍待完成。
