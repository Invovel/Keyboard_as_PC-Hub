# R0结构尺寸、接口坐标与建模依据

更新：2026-10-09。用户要求根据目前功能给出具体尺寸，以下冻结的是**R0布局名义值**，用于建模和散件试装；制造尚未放行。散件电气验证仍先于集成PCB。所有尺寸单位mm。

| 项目 | R0数值 | 说明 |
| --- | --- | --- |
| 主机外壳宽×深 | 112×92 | 左侧完整独立主机 |
| 前高/后高 | 24/32.05 | 不含脚垫与突出的控件；92×tan(5°)=8.05 |
| 操作面倾角 | 5° | 相对外壳底面 |
| 壁厚/底厚 | 2.4/2.4 | 首轮打印结构参数，非打印精度保证 |
| 外壳角部半径 | R4 | 布局初值 |
| 主PCB宽×深×厚 | 100×80×1.6 | 主板居中，四周名义边距6 |
| 主PCB安装孔 | 暂定4×Ø2.7 | 孔中心相对PCB左前角：(4,4)、(96,4)、(4,76)、(96,76)；在器件布置时避开 |
| 右侧模块载体 | 112×92 | 五键及独立触控条拼装在其中 |

| 组合最大高度预留 | 50 | 包括常规键帽、旋钮及脚垫的早期包络，最终随实际轴/帽修正 |

112×92主机内腔平面名义107.2×87.2，100×80主板与内壁各留3.6；此余量包含安装/装配空间，仍需检查螺柱、连接器焊脚、板边天线和走线。不能据此声称所有功能已放得下。

## 2. 控件平面布局

定义各模块壳体左前角为(0,0)，X向右、Y向后。坐标是顶视投影，不是已出孔图。

| 控件 | 中心/包络 |
| --- | --- |
| 主机中央圆屏旋钮 | 中心(56,46)，硬质旋转外圈外径60，露出操作面高度8 |
| 屏幕背部安装预留 | 中心同上，平面48×48、向下深12；这是待实测占位，不是屏幕真实尺寸 |
| F1左上软键 | 中心(17,73)，接触面18×18 |
| F2右上软键 | 中心(95,73)，接触面18×18 |
| F3左下软键 | 中心(17,19)，接触面18×18 |
| F4右下软键 | 中心(95,19)，接触面18×18 |
| 软键厚度 | 先预留8–12；微结构、磁铁仓和传感器间距必须另试验 |
| STOP | 主机前壁中部，按钮头初选Ø10，实际开孔随选件 |
| 五键中心 | 右模块局部X=17.9、36.95、56、75.05、94.1；Y=58 |
| 触控条 | 右模块中心(56,19)，外壳包络104×22 |

四软键与外径60旋钮顶视上不重叠；这不是磁场隔离验证。屏幕48×48的背部占位与旋钮/按压承托需要三维联合设计，不能仅凭外径60判断机构成立。

五键板前后可为连接器和未来模块预留空间，首版不为填满92mm深度而增加功能。机械旋钮及按压载荷由独立支架承受，不压屏幕和四软键。

## 3. 接口面板布置

背面观察按主机坐标X计，五口沿横向排列。初始中心高度Z=13，相对外壳底面。外壳插孔高度一致不意味着连接器可不经处理焊在同一高度PCB上；后续应选对安装高度、采用接口小板或调整面板坐标。

| 接口 | X中心 | 面板暂用避让窗 | 内部深度预留 |
| --- | ---: | --- | ---: |
| USB-A1 | 14 | 15×8 | 22 |
| USB-A2 | 34 | 15×8 | 22 |
| USB-A3 | 54 | 15×8 | 22 |
| PC Type-C | 78 | 11×5 | 15 |
| POWER Type-C | 98 | 11×5 | 15 |

避让窗是打印试装参数，不是金属插口尺寸；最终根据真实母座壳体、偏位公差和插头外壳调整。A口20mm中心距可用于小型插头/接收器布局，宽体U盘仍可能遮挡相邻口，不能保证任意大插头同时插入。

FAST放在**主机左侧面**（不会被右侧五键模块遮挡），初始中心Y=60、Z=13，暂用11×5避让窗、内部深度预留15。外侧另留至少30mm的初始插头操作区，线缆弯曲空间依据所用线材追加；不能将30mm当作USB线的统一弯曲半径。

PC和FAST选真正支持USB 3.2 Gen2的连接器；POWER只供电，可用不同针数和结构的C座。键盘公头是Hub下游，不能与电脑上行互换。

键盘端：仍采用后接/侧接两种安装方向，中心离桌高度夹具范围5–25，肩部后退量试件5/10/15。标准金属插头长度不改。整机壳体不需要与键盘对齐，但必须独立承力。

## 5. 必须在下一阶段关闭的尺寸问题

- 核对屏幕完整PCB、显示区域、连接器和排线弯曲空间，再设计中空旋钮及按压支架。
- 实际选择磁吸触点座并取得图纸；六触点只定义电气数量，不预设连接器外形已定。
- 确定Hub、PD/降压、音频及天线区域，检查100×80板框能否布局；散件整板不强行塞入此壳。
- 36W预留并发负载及转换损耗需要温升验证；24–32mm壳高不代表已经解决散热。必要时增加通风或调整尺寸。
- 外壳尺寸可先用纸板/无电试装壳验证；屏幕孔、USB开孔、螺柱和精密插接件未确认前不下单最终加工。
